A calendar for picking a date, several dates or a date range. `Calendar` is the shadcn/ui calendar,
built on [React DayPicker](https://daypicker.dev) v10, and accepts all of its props. For a date
input with a popover, use `DatePicker`.

<Example>
  <CalendarExample />

  ```jsx
  function CalendarExample() {
    const [date, setDate] = useState(new Date());

    return (
      <Column alignItems="center" gap="3">
        <Calendar mode="single" selected={date} onSelect={setDate} className="rounded-lg border" />
        <Text size="sm" color="muted">
          {date ? date.toDateString() : 'No date selected'}
        </Text>
      </Column>
    );
  }
  ```
</Example>

## Range

Set `mode="range"` to select a start and end date. `selected` is then a `{ from, to }` object.
Without `selected`, the calendar manages the selection itself.

<Example>
  <Calendar mode="range" numberOfMonths={2} className="rounded-lg border" />

  ```jsx
  <Calendar mode="range" numberOfMonths={2} className="rounded-lg border" />
  ```
</Example>

## Month and year selector

Use `captionLayout="dropdown"` to jump between months and years.

<Example>
  <Calendar mode="single" captionLayout="dropdown" className="rounded-lg border" />

  ```jsx
  <Calendar mode="single" captionLayout="dropdown" className="rounded-lg border" />
  ```
</Example>

## Disabled dates

`disabled` takes a date, an array of dates or a matcher such as `{ before: date }` or
`{ dayOfWeek: [0, 6] }`.

<Example>
  <Calendar mode="single" disabled={{ dayOfWeek: [0, 6] }} className="rounded-lg border" />

  ```jsx
  <Calendar mode="single" disabled={{ dayOfWeek: [0, 6] }} className="rounded-lg border" />
  ```
</Example>

## Component props

The most common props are listed below. See the [React DayPicker docs](https://daypicker.dev) for
the full API.

  <PropertiesTable.Row name="onSelect" type="(selected, triggerDate, modifiers, event) => void">Called when the selection changes</PropertiesTable.Row>
  <PropertiesTable.Row name="required" type="boolean">Prevents the selection from being cleared</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="Matcher | Matcher[]">Days that can't be selected</PropertiesTable.Row>
  <PropertiesTable.Row name="startMonth" type="Date">The earliest month that can be navigated to</PropertiesTable.Row>
  <PropertiesTable.Row name="endMonth" type="Date">The latest month that can be navigated to</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultMonth" type="Date">The month shown first</PropertiesTable.Row>
