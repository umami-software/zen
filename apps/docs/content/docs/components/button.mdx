import { Button, Example, Lucide, Spinner } from '../../../mdx-components';

Displays a button or a component that looks like a button. `Button` is the shadcn/ui button built on
the Base UI `Button` primitive.

<Example>
  <Button>Button</Button>

  ```jsx
  <Button>Button</Button>
  ```
</Example>

## Variants

`default` is the primary action. Use `secondary` for neutral actions, `outline` and `ghost` for
lower emphasis, `destructive` for dangerous actions and `link` for a text link style.

<Example direction="row">
  <Button>Default</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="destructive">Destructive</Button>
  <Button variant="link">Link</Button>

  ```jsx
  <Button>Default</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="destructive">Destructive</Button>
  <Button variant="link">Link</Button>
  ```
</Example>

## Icon

Use the `icon`, `icon-xs`, `icon-sm` or `icon-lg` sizes for square icon-only buttons, and give them
an `aria-label`.

## With icon

Place an svg next to the label. Add `data-icon="inline-start"` or `data-icon="inline-end"` to tighten
the padding on that side.

<Example direction="row">
  <Button variant="outline">
    <Lucide.GitBranch data-icon="inline-start" />
    New branch
  </Button>
  <Button variant="secondary">
    Continue
    <Lucide.ArrowRight data-icon="inline-end" />
  </Button>

  ```jsx
  <Button variant="outline">
    <Lucide.GitBranch data-icon="inline-start" />
    New branch
  </Button>
  <Button variant="secondary">
    Continue
    <Lucide.ArrowRight data-icon="inline-end" />
  </Button>
  ```
</Example>

<Example direction="row">

    Submitting
  </Button>


## Link

Use the `render` prop to render a button as a link or a router link. Set `nativeButton={false}` when
the rendered element is not a `<button>`.

<Example>
  <Button variant="outline" render={<a href="#" />} nativeButton={false}>
    Go to page
  </Button>

  ```jsx
  <Button variant="outline" render={<a href="#" />} nativeButton={false}>
    Go to page
  </Button>
  ```
</Example>

To style another element as a button without rendering `Button`, use `buttonVariants`:

```jsx
<a href="/login" className={buttonVariants({ variant: 'outline' })}>
  Login
</a>
```
