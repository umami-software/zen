## Controlled

```jsx
const [open, setOpen] = useState(false);

<Collapsible open={open} onOpenChange={setOpen}>
  <CollapsibleTrigger render={<Button variant="outline" />}>Toggle</CollapsibleTrigger>
  <CollapsibleContent>...</CollapsibleContent>
</Collapsible>
```

## Parts

- `Collapsible` is the root. It holds the open state.
- `CollapsibleTrigger` toggles the panel. Use `render={<Button />}` to style it.
- `CollapsibleContent` is the panel that is shown and hidden.
