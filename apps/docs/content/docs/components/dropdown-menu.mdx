`DropdownMenuLabel` must be placed inside a `DropdownMenuGroup` (or a `DropdownMenuRadioGroup`).

## Icons and destructive items

Put an svg before the label. Set `variant="destructive"` on items that delete or remove things.

      <Lucide.MoreHorizontal />
    </DropdownMenuTrigger>
    <DropdownMenuContent align="end">
      <DropdownMenuGroup>
        <DropdownMenuItem>
          <Lucide.Pencil />
          Edit
        </DropdownMenuItem>
        <DropdownMenuItem>
          <Lucide.Copy />
          Duplicate

        <DropdownMenuItem variant="destructive">

## Checkboxes

`DropdownMenuCheckboxItem` toggles a setting. Control it with `checked` and `onCheckedChange`, or
use `defaultChecked`.

<Example>
  <DropdownMenu>
    <DropdownMenuTrigger render={<Button variant="outline" />}>View</DropdownMenuTrigger>
    <DropdownMenuContent>
      <DropdownMenuGroup>
        <DropdownMenuLabel>Appearance</DropdownMenuLabel>
        <DropdownMenuCheckboxItem defaultChecked>Status bar</DropdownMenuCheckboxItem>
        <DropdownMenuCheckboxItem disabled>Activity bar</DropdownMenuCheckboxItem>
        <DropdownMenuCheckboxItem>Panel</DropdownMenuCheckboxItem>
      </DropdownMenuGroup>
    </DropdownMenuContent>
  </DropdownMenu>


## Radio group

`DropdownMenuRadioGroup` selects one value. Control it with `value` and `onValueChange`, or use
`defaultValue`.

<Example>
  <DropdownMenu>
    <DropdownMenuTrigger render={<Button variant="outline" />}>Panel position</DropdownMenuTrigger>
    <DropdownMenuContent>
      <DropdownMenuGroup>
        <DropdownMenuLabel>Panel position</DropdownMenuLabel>
        <DropdownMenuRadioGroup defaultValue="bottom">
          <DropdownMenuRadioItem value="top">Top</DropdownMenuRadioItem>
          <DropdownMenuRadioItem value="bottom">Bottom</DropdownMenuRadioItem>
          <DropdownMenuRadioItem value="right">Right</DropdownMenuRadioItem>
        </DropdownMenuRadioGroup>
      </DropdownMenuGroup>
    </DropdownMenuContent>
  </DropdownMenu>

## Links

Use `render` to make an item a link or a router link.

```jsx
<DropdownMenuItem render={<a href="/settings" />}>Settings</DropdownMenuItem>
<DropdownMenuItem render={<Link to="/profile" />}>Profile</DropdownMenuItem>
```

## Parts

- `DropdownMenu` is the root. `DropdownMenuTrigger` opens it; use `render={<Button />}` to style it.
- `DropdownMenuContent` is the popup.
- `DropdownMenuItem` is an action. Handle it with `onClick`.
- `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup` and `DropdownMenuRadioItem` hold a selected state.
- `DropdownMenuGroup` groups items, and `DropdownMenuLabel` labels a group.
- `DropdownMenuSub`, `DropdownMenuSubTrigger` and `DropdownMenuSubContent` build a submenu.
- `DropdownMenuSeparator` divides groups, and `DropdownMenuShortcut` shows a shortcut hint.

### DropdownMenuContent

<PropertiesTable>
  <PropertiesTable.Row name="side" type="string">"top" | "bottom" | "left" | "right" | "inline-start" | "inline-end" (default: "bottom")</PropertiesTable.Row>
