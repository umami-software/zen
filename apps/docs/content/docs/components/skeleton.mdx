import { Box, Column, Example, Row, Skeleton } from '../../../mdx-components';

Use to show a placeholder while content is loading. `Skeleton` is a pulsing `div` that fills the
width of its container; set its size and shape with `className`, or size it with a wrapping
layout component.

## Text

## Component props

`Skeleton` takes standard `div` props, including `className` and `style`. In a Tailwind app, size
it directly, for example `<Skeleton className="h-4 w-[250px]" />`.

The `SkeletonText` and `SkeletonAvatar` helpers are removed in 1.0; compose `Skeleton` as above
instead.
