A fast, composable command menu with search and keyboard navigation, built on
[cmdk](https://github.com/pacocoursey/cmdk). Items are filtered as the user types.

## Dialog

`CommandDialog` shows the menu in a `Dialog`. Put a `Command` inside it and control it with `open`
and `onOpenChange`, for example from a keyboard shortcut.

<Example>
  <CommandDialogExample />

  ```jsx
  function CommandDialogExample() {
    const [open, setOpen] = useState(false);

    useEffect(() => {
      const onKeyDown = (event) => {
        if (event.key === 'j' && (event.metaKey || event.ctrlKey)) {
          event.preventDefault();
          setOpen(open => !open);
        }
      };

      document.addEventListener('keydown', onKeyDown);
      return () => document.removeEventListener('keydown', onKeyDown);
    }, []);

    return (
      <>
        <Row alignItems="center" gap="3">
          <Button variant="outline" onClick={() => setOpen(true)}>
            Open command palette
          </Button>
          <Text size="sm" color="muted-foreground">
            or press{' '}
            <KbdGroup>
              <Kbd>⌘</Kbd>
              <Kbd>J</Kbd>
            </KbdGroup>
          </Text>
        </Row>
        <CommandDialog open={open} onOpenChange={setOpen}>
          <Command>
            <CommandInput placeholder="Type a command or search..." />
            <CommandList>
              <CommandEmpty>No results found.</CommandEmpty>
              <CommandGroup heading="Suggestions">
                <CommandItem onSelect={() => setOpen(false)}>
                  <Calendar />
                  <span>Calendar</span>
                </CommandItem>
                <CommandItem onSelect={() => setOpen(false)}>
                  <Smile />
                  <span>Search emoji</span>
                </CommandItem>
              </CommandGroup>
              <CommandSeparator />
              <CommandGroup heading="Settings">
                <CommandItem onSelect={() => setOpen(false)}>
                  <User />
                  <span>Profile</span>
                </CommandItem>
                <CommandItem onSelect={() => setOpen(false)}>
                  <Settings />
                  <span>Settings</span>
                </CommandItem>
              </CommandGroup>
            </CommandList>
          </Command>
        </CommandDialog>
      </>
    );
  }
  ```
</Example>

## Parts

- `Command` is the root. It filters and sorts the items.
- `CommandInput` is the search input.
- `CommandList` holds the results. `CommandEmpty` shows when nothing matches.
- `CommandGroup` groups items under a `heading`. `CommandSeparator` divides groups.
- `CommandItem` is one action. `CommandShortcut` shows its keyboard shortcut.
- `CommandDialog` shows a `Command` in a dialog.
