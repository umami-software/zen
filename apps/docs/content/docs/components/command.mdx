A command palette for searching and running actions with keyboard navigation.

<Example>
  <CommandExample />

  ```jsx
  <Command>
    <CommandInput placeholder="Type a command or search..." />
    <CommandList>
      <CommandEmpty>No results found.</CommandEmpty>
      <CommandGroup heading="Suggestions">
        <CommandItem icon={<Calendar />}>Calendar</CommandItem>
        <CommandItem icon={<Smile />}>Search emoji</CommandItem>
        <CommandItem icon={<Search />} isDisabled>
          Search web
        </CommandItem>
      </CommandGroup>
      <CommandSeparator />
      <CommandGroup heading="Settings">
        <CommandItem icon={<User />}>Profile</CommandItem>
        <CommandItem icon={<Settings />}>Settings</CommandItem>
      </CommandGroup>
    </CommandList>
  </Command>
  ```
</Example>

## Dialog

Use `CommandDialog` to display the command palette in a modal overlay. Control visibility
with the `isOpen` and `onOpenChange` props.

<Example>
  <CommandDialogExample />

  ```jsx
  function App() {
    const [isOpen, setIsOpen] = useState(false);

    return (
      <>
        <Button variant="primary" onPress={() => setIsOpen(true)}>
          Open command palette
        </Button>
        <CommandDialog isOpen={isOpen} onOpenChange={setIsOpen}>
          <CommandInput placeholder="Type a command or search..." />
          <CommandList>
            <CommandEmpty>No results found.</CommandEmpty>
            <CommandGroup heading="Suggestions">
              <CommandItem icon={<Calendar />} onSelect={() => setIsOpen(false)}>
                Calendar
              </CommandItem>
              <CommandItem icon={<Smile />} onSelect={() => setIsOpen(false)}>
                Search emoji
              </CommandItem>
            </CommandGroup>
          </CommandList>
        </CommandDialog>
      </>
    );
  }
  ```
</Example>

## Component props

### Command

<PropertiesTable>
  <ResponseField name="value" type="string">Controlled value of the selected item</ResponseField>
  <ResponseField name="onValueChange" type="(value: string) => void">Called when the selected item changes</ResponseField>
  <ResponseField name="filter" type="(value, search, keywords) => number">Custom filter function for ranking items</ResponseField>
  <ResponseField name="shouldFilter" type="boolean">Disable built-in filtering when false</ResponseField>
  <ResponseField name="loop" type="boolean">Loop keyboard navigation from last item to first</ResponseField>
</PropertiesTable>

### CommandInput

<PropertiesTable>
  <ResponseField name="placeholder" type="string">Input placeholder text</ResponseField>
  <ResponseField name="value" type="string">Controlled search value</ResponseField>
  <ResponseField name="onValueChange" type="(search: string) => void">Called when the search value changes</ResponseField>
</PropertiesTable>

### CommandGroup

<PropertiesTable>
  <ResponseField name="heading" type="ReactNode">Group heading displayed above items</ResponseField>
</PropertiesTable>

### CommandItem

<PropertiesTable>
  <ResponseField name="icon" type="ReactNode">Icon displayed before the label</ResponseField>
  <ResponseField name="isDisabled" type="boolean">Disables the item (`disabled` is also accepted)</ResponseField>
  <ResponseField name="value" type="string">Value used for filtering (defaults to text content)</ResponseField>
  <ResponseField name="keywords" type="string[]">Additional keywords used when filtering</ResponseField>
  <ResponseField name="onSelect" type="(value: string) => void">Called when the item is selected</ResponseField>
</PropertiesTable>

### CommandList

<PropertiesTable>
  <ResponseField name="maxHeight" type="string | number">Wraps the list in a `ScrollArea` capped at this height. Without it the list scrolls natively at `max-h-[300px]`</ResponseField>
</PropertiesTable>

### CommandShortcut

Renders a right-aligned muted `<span>` for keyboard shortcut hints inside a `CommandItem`.

```jsx
<CommandItem>
  Settings
  <CommandShortcut>⌘S</CommandShortcut>
</CommandItem>
```

### CommandDialog

<PropertiesTable>
  <ResponseField name="open" type="boolean">Whether the dialog is open (`isOpen` is an accepted alias)</ResponseField>
  <ResponseField name="onOpenChange" type="(open: boolean) => void">Called when the open state changes</ResponseField>
</PropertiesTable>

## Anatomy

Every part exposes a `data-slot` attribute: `command`, `command-input-wrapper`, `command-input`,
`command-list`, `command-empty`, `command-group`, `command-separator`, `command-item`, and
`command-shortcut`. Inside `CommandDialog` the input wrapper grows to `h-12`.
