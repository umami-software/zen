import { Avatar, AvatarBadge, AvatarFallback, AvatarGroup, AvatarGroupCount, AvatarImage, Example, Row } from '../../../mdx-components';

An image element with a fallback for representing the user. The `AvatarFallback` is shown while
the image loads and when it fails to load.

<Example>
  <Row gap="4" alignItems="center">
    <Avatar>
      <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
    <Avatar>
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
  </Row>

  ```jsx
  <Avatar>
    <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
    <AvatarFallback>JD</AvatarFallback>
  </Avatar>
  <Avatar>
    <AvatarFallback>JD</AvatarFallback>
  </Avatar>
  ```
</Example>

## Badge

`AvatarBadge` adds a status dot to the bottom-right corner.

<Example>
  <Avatar size="lg">
    <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
    <AvatarFallback>JD</AvatarFallback>
    <AvatarBadge />
  </Avatar>

  ```jsx
  <Avatar size="lg">
    <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
    <AvatarFallback>JD</AvatarFallback>
    <AvatarBadge />
  </Avatar>
  ```
</Example>

## Group

Stack avatars with `AvatarGroup`, and show the remainder with `AvatarGroupCount`.

<Example>
  <AvatarGroup>
    <Avatar>
      <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
    <Avatar>
      <AvatarFallback>MC</AvatarFallback>
    </Avatar>
    <Avatar>
      <AvatarFallback>AB</AvatarFallback>
    </Avatar>
    <AvatarGroupCount>+3</AvatarGroupCount>
  </AvatarGroup>

  ```jsx
  <AvatarGroup>
    <Avatar>
      <AvatarImage src="/images/sample.jpg" alt="Jane Doe" />
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>
    <Avatar>
      <AvatarFallback>MC</AvatarFallback>
    </Avatar>
    <Avatar>
      <AvatarFallback>AB</AvatarFallback>
    </Avatar>
    <AvatarGroupCount>+3</AvatarGroupCount>
  </AvatarGroup>
  ```
</Example>

  <PropertiesTable.Row name="AvatarBadge" type="span">Status dot in the bottom-right corner</PropertiesTable.Row>
  <PropertiesTable.Row name="AvatarGroup" type="div">Overlaps a row of avatars</PropertiesTable.Row>
  <PropertiesTable.Row name="AvatarGroupCount" type="div">A trailing count inside `AvatarGroup`</PropertiesTable.Row>
</PropertiesTable>
