title: Loading Button

import { Example, LoadingButton } from '../../../mdx-components';

A button that indicates an action is still pending. It is a shadcn `Button` that shows a `Spinner`
before its content and is disabled while `loading` is true.

<Example>
  <LoadingButton loading>Saving...</LoadingButton>

  ```jsx
  <LoadingButton loading>Saving...</LoadingButton>
  ```
</Example>

## Variants

<Example>
  <LoadingButton loading>Loading...</LoadingButton>
  <LoadingButton variant="secondary" loading>Loading...</LoadingButton>
  <LoadingButton variant="outline" loading>Loading...</LoadingButton>
  <LoadingButton variant="ghost" loading>Loading...</LoadingButton>
  <LoadingButton variant="destructive" loading>Loading...</LoadingButton>

  ```jsx
  <LoadingButton loading>Loading...</LoadingButton>
  <LoadingButton variant="secondary" loading>Loading...</LoadingButton>
  <LoadingButton variant="outline" loading>Loading...</LoadingButton>
  <LoadingButton variant="ghost" loading>Loading...</LoadingButton>
  <LoadingButton variant="destructive" loading>Loading...</LoadingButton>
  ```
</Example>

## Not loading

When `loading` is false it renders as a regular button.

<Example>
  <LoadingButton>Save</LoadingButton>
  <LoadingButton disabled>Save</LoadingButton>

  ```jsx
  <LoadingButton>Save</LoadingButton>
  <LoadingButton disabled>Save</LoadingButton>
  ```
</Example>

## Component props

All shadcn `Button` props are supported.

<PropertiesTable>
  <PropertiesTable.Row name="loading" type="boolean">Shows a spinner and disables the button (default: false)</PropertiesTable.Row>
  <PropertiesTable.Row name="variant" type="string">"default" | "secondary" | "outline" | "ghost" | "destructive" | "link"</PropertiesTable.Row>
  <PropertiesTable.Row name="size" type="string">"default" | "xs" | "sm" | "lg" | "icon" | "icon-xs" | "icon-sm" | "icon-lg"</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Disables the button</PropertiesTable.Row>
</PropertiesTable>
