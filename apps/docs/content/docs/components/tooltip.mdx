A popup that displays information related to an element when the element receives keyboard focus
or the mouse hovers over it. Use the `render` prop on `TooltipTrigger` to render it as your own
button.

<Example>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" />}>Hover</TooltipTrigger>
    <TooltipContent>
      <p>Add to library</p>
    </TooltipContent>
  </Tooltip>

  ```jsx
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" />}>Hover</TooltipTrigger>
    <TooltipContent>
      <p>Add to library</p>
    </TooltipContent>
  </Tooltip>
  ```
</Example>

## Icon button

Tooltips are a good way to label icon-only buttons. Content can include a keyboard shortcut.

<Example>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" size="icon" aria-label="Save" />}>
      <Lucide.Save />
    </TooltipTrigger>
    <TooltipContent>
      Save <Kbd>⌘S</Kbd>
    </TooltipContent>
  </Tooltip>

  ```jsx
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" size="icon" aria-label="Save" />}>
      <Lucide.Save />
    </TooltipTrigger>
    <TooltipContent>
      Save <Kbd>⌘S</Kbd>
    </TooltipContent>
  </Tooltip>
  ```
</Example>

## Disabled button

A disabled button doesn't fire pointer events. Wrap it in a `span` so the tooltip can still show.

<Example>
  <Tooltip>
    <TooltipTrigger render={<span tabIndex={0} />}>
      <Button variant="outline" disabled>
        Disabled
      </Button>
    </TooltipTrigger>
    <TooltipContent>This feature is unavailable</TooltipContent>
  </Tooltip>

  ```jsx
  <Tooltip>
    <TooltipTrigger render={<span tabIndex={0} />}>
      <Button variant="outline" disabled>
        Disabled
      </Button>
    </TooltipTrigger>
    <TooltipContent>This feature is unavailable</TooltipContent>
  </Tooltip>
  ```
</Example>

## Provider

`ZenProvider` wraps the app in a `TooltipProvider`, which shares the open delay across tooltips so
moving between them opens the next one instantly. Configure it with `ZenProvider`'s `tooltip` prop,
for example `<ZenProvider tooltip={{ delay: 300 }}>`. Set `delay` and `closeDelay` on a single
`TooltipTrigger` to override it.

## Floating

`FloatingTooltip` is a Zen component that follows the cursor. Show it with `open`.

<Example>
  <FloatingTooltipExample />

  ```jsx
  const [show, setShow] = useState(false);

  <Box
    backgroundColor="muted"
    borderRadius
    width="400px"
    height="300px"
    onMouseEnter={() => setShow(true)}
    onMouseLeave={() => setShow(false)}
  />
  <FloatingTooltip open={show}>
    <Text color="background">Hello</Text>
  </FloatingTooltip>
  ```
</Example>

## Parts

### Tooltip

<PropertiesTable>
  <PropertiesTable.Row name="open" type="boolean">Controlled open state</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultOpen" type="boolean">Initial open state when uncontrolled</PropertiesTable.Row>
  <PropertiesTable.Row name="onOpenChange" type="(open: boolean, details) => void">Called when the tooltip opens or closes</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Prevents the tooltip from opening</PropertiesTable.Row>
</PropertiesTable>

### TooltipTrigger

<PropertiesTable>
  <PropertiesTable.Row name="render" type="ReactElement | function">Replaces the rendered `button`, e.g. `render={<Button variant="outline" />}`</PropertiesTable.Row>
  <PropertiesTable.Row name="delay" type="number">Milliseconds before opening. Overrides the provider</PropertiesTable.Row>
  <PropertiesTable.Row name="closeDelay" type="number">Milliseconds before closing. Overrides the provider</PropertiesTable.Row>
</PropertiesTable>

### TooltipContent

<PropertiesTable>
  <PropertiesTable.Row name="side" type="string">"top" | "right" | "bottom" | "left" | "inline-start" | "inline-end" (default: "top")</PropertiesTable.Row>
  <PropertiesTable.Row name="align" type="string">"start" | "center" | "end" (default: "center")</PropertiesTable.Row>
  <PropertiesTable.Row name="sideOffset" type="number">Distance from the trigger in pixels (default: 4)</PropertiesTable.Row>
  <PropertiesTable.Row name="alignOffset" type="number">Offset along the alignment axis in pixels (default: 0)</PropertiesTable.Row>
</PropertiesTable>

`TooltipProvider` is also exported, for apps that don't use `ZenProvider`.
