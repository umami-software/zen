## Controlled

```jsx
const [pressed, setPressed] = useState(false);

<Toggle pressed={pressed} onPressedChange={setPressed} aria-label="Toggle bold">
  <Lucide.Bold />
</Toggle>
```

## Component props

<PropertiesTable>
  <PropertiesTable.Row name="pressed" type="boolean">Controlled pressed state</PropertiesTable.Row>

`toggleVariants({ variant, size })` returns the class names, for styling other elements as a toggle.
