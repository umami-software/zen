A badge displays a small label used to highlight a status or category.

<Example>
  <Badge>Badge</Badge>

  ```jsx
  <Badge>Badge</Badge>
  ```
</Example>

## Variants

<Example>
  <Badge variant="default">Default</Badge>
  <Badge variant="primary">Primary</Badge>
  <Badge variant="outline">Outline</Badge>
  <Badge variant="success">Success</Badge>
  <Badge variant="warning">Warning</Badge>
  <Badge variant="error">Error</Badge>
  <Badge variant="info">Info</Badge>

  ```jsx
  <Badge variant="default">Default</Badge>
  <Badge variant="primary">Primary</Badge>
  <Badge variant="outline">Outline</Badge>
  <Badge variant="success">Success</Badge>
  <Badge variant="warning">Warning</Badge>
  <Badge variant="error">Error</Badge>
  <Badge variant="info">Info</Badge>
  ```
</Example>

## Colors

In addition to the semantic variants above, `Badge` supports every Tailwind base color as a variant.
