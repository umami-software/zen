Displays a badge or a component that looks like a badge.

<Example>
  <Badge>Badge</Badge>

  ```jsx
  <Badge>Badge</Badge>
  ```
</Example>

## Variants

<Example>
  <Row gap="2" wrap="wrap" justifyContent="center">
    <Badge>Default</Badge>
    <Badge variant="secondary">Secondary</Badge>
    <Badge variant="destructive">Destructive</Badge>
    <Badge variant="outline">Outline</Badge>
    <Badge variant="ghost">Ghost</Badge>
    <Badge variant="link">Link</Badge>
  </Row>

  ```jsx
  <Badge>Default</Badge>
  <Badge variant="secondary">Secondary</Badge>
  <Badge variant="destructive">Destructive</Badge>
  <Badge variant="outline">Outline</Badge>
  <Badge variant="ghost">Ghost</Badge>
  <Badge variant="link">Link</Badge>
  ```
</Example>

## With icon

Mark the icon with `data-icon="inline-start"` or `data-icon="inline-end"` to tighten the padding
on that side.

<Example>
  <Row gap="2" wrap="wrap" justifyContent="center">
    <Badge variant="secondary">
      <Lucide.BadgeCheck data-icon="inline-start" />
      Verified
    </Badge>
    <Badge variant="outline">
      Bookmark
      <Lucide.Bookmark data-icon="inline-end" />
    </Badge>
  </Row>

  ```jsx
  <Badge variant="secondary">
    <Lucide.BadgeCheck data-icon="inline-start" />
    Verified
  </Badge>
  <Badge variant="outline">
    Bookmark
    <Lucide.Bookmark data-icon="inline-end" />
  </Badge>
  ```
</Example>

## As a link

Use the `render` prop to render the badge as another element, such as a link.

<Example>
  <Badge render={<a href="#as-a-link" />}>
    Open link
    <Lucide.ArrowUpRight data-icon="inline-end" />
  </Badge>

  ```jsx
  <Badge render={<a href="#as-a-link" />}>
    Open link
    <Lucide.ArrowUpRight data-icon="inline-end" />
  </Badge>
  ```
</Example>

  <PropertiesTable.Row name="variant" type="string">"default" | "secondary" | "destructive" | "outline" | "ghost" | "link" (default: "default")</PropertiesTable.Row>
