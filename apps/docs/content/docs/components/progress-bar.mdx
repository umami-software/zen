---
title: Progress Bar
---

import { Example, ProgressBar } from '../../../mdx-components';

A horizontal bar that visually represents the completion status of a task or process. Supports determinate progress with percentage values and optional value labels.

<Example>
  <ProgressBar value={50} />

  ```jsx
  <ProgressBar value={50} />
  ```
</Example>

## Show percentage

<Example>
  <ProgressBar value={25} showPercentage />

  ```jsx
  <ProgressBar value={25} showPercentage />
  ```
</Example>

## Component props

<PropertiesTable>
  <ResponseField name="value" type="number">Current progress value</ResponseField>
  <ResponseField name="minValue" type="number">Minimum value (default: 0)</ResponseField>
  <ResponseField name="maxValue" type="number">Maximum value (default: 100)</ResponseField>
  <ResponseField name="showPercentage" type="boolean">Shows percentage text</ResponseField>
</PropertiesTable>
