Displays a keyboard key or shortcut.

<Example>
  <KbdGroup>
    <Kbd>⌘</Kbd>
    <Kbd>⇧</Kbd>
    <Kbd>⌥</Kbd>
    <Kbd>⌃</Kbd>
  </KbdGroup>

  ```jsx
  <KbdGroup>
    <Kbd>⌘</Kbd>
    <Kbd>⇧</Kbd>
    <Kbd>⌥</Kbd>
    <Kbd>⌃</Kbd>
  </KbdGroup>
  ```
</Example>

## Group

Use `KbdGroup` to keep the keys of a shortcut together.

<Example>
  <Column gap="3" alignItems="center">
    <Text size="sm" color="muted-foreground">
      Use{' '}
      <KbdGroup>
        <Kbd>Ctrl + B</Kbd>
        <Kbd>Ctrl + K</Kbd>
      </KbdGroup>{' '}
      to open the command palette.
    </Text>
    <KbdGroup>
      <Kbd>Ctrl</Kbd>
      <span>+</span>
      <Kbd>Shift</Kbd>
      <span>+</span>
      <Kbd>P</Kbd>
    </KbdGroup>
  </Column>

  ```jsx
  <Column gap="3" alignItems="center">
    <Text size="sm" color="muted-foreground">
      Use{' '}
      <KbdGroup>
        <Kbd>Ctrl + B</Kbd>
        <Kbd>Ctrl + K</Kbd>
      </KbdGroup>{' '}
      to open the command palette.
    </Text>
    <KbdGroup>
      <Kbd>Ctrl</Kbd>
      <span>+</span>
      <Kbd>Shift</Kbd>
      <span>+</span>
      <Kbd>P</Kbd>
    </KbdGroup>
  </Column>
  ```
</Example>

## Button

A `Kbd` inside a button shows the button's shortcut.

<Example>
  <Button variant="outline">
    Accept <Kbd>⏎</Kbd>
  </Button>

  ```jsx
  <Button variant="outline">
    Accept <Kbd>⏎</Kbd>
  </Button>
  ```
</Example>

## Component props

`Kbd` renders a native `kbd` element and `KbdGroup` renders a `kbd` that wraps several keys. Both
accept the standard HTML props.
