import { Button, ButtonGroup, ButtonGroupSeparator, ButtonGroupText, DataColumn, DataTable, Example, Icon, Label, Lucide, Menu, MenuItem, MenuSeparator, MenuTrigger, TextField, ZenProvider } from '../../../mdx-components';

<ZenProvider>

A button group places related actions together with consistent spacing, borders, and focus
behavior. Label each group with `aria-label` or `aria-labelledby`.

<Example direction="row" minHeight="160px">
  <ButtonGroup aria-label="Inbox actions">
    <ButtonGroup>
      <Button variant="outline" aria-label="Go back">
        <Icon size="sm"><Lucide.ArrowLeft /></Icon>
      </Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Archive</Button>
      <Button variant="outline">Report</Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Snooze</Button>
      <MenuTrigger>
        <Button variant="outline" aria-label="More options">
          <Icon size="sm"><Lucide.MoreHorizontal /></Icon>
        </Button>
        <Menu>
          <MenuItem id="mark-read">Mark as read</MenuItem>
          <MenuItem id="archive">Archive</MenuItem>
          <MenuSeparator />
          <MenuItem id="add-calendar">Add to calendar</MenuItem>
          <MenuItem id="trash">Trash</MenuItem>
        </Menu>
      </MenuTrigger>
    </ButtonGroup>
  </ButtonGroup>

  ```jsx
  <ButtonGroup aria-label="Inbox actions">
    <ButtonGroup>
      <Button variant="outline" aria-label="Go back">
        <Icon size="sm"><ArrowLeft /></Icon>
      </Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Archive</Button>
      <Button variant="outline">Report</Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Snooze</Button>
      <MenuTrigger>
        <Button variant="outline" aria-label="More options">
          <Icon size="sm"><MoreHorizontal /></Icon>
        </Button>
        <Menu>
          <MenuItem id="mark-read">Mark as read</MenuItem>
          <MenuItem id="archive">Archive</MenuItem>
          <MenuSeparator />
          <MenuItem id="add-calendar">Add to calendar</MenuItem>
          <MenuItem id="trash">Trash</MenuItem>
        </Menu>
      </MenuTrigger>
    </ButtonGroup>
  </ButtonGroup>
  ```
</Example>

Use `ButtonGroup` for actions. Use `ToggleGroup` when the controls represent persistent selected
states.

## Separator

Use a separator between borderless button variants. Outline buttons already provide their own
dividers.

<Example direction="row" minHeight="160px">
  <ButtonGroup aria-label="Clipboard actions">
    <Button size="sm">Copy</Button>
    <ButtonGroupSeparator />
    <Button size="sm">Paste</Button>
  </ButtonGroup>

  ```jsx
  <ButtonGroup aria-label="Clipboard actions">
    <Button size="sm">Copy</Button>
    <ButtonGroupSeparator />
    <Button size="sm">Paste</Button>
  </ButtonGroup>
  ```
</Example>

## Text

`ButtonGroupText` adds non-interactive content to the group. Use `render` when the text needs
different semantics, such as a form label.

<Example direction="row" minHeight="160px">
  <ButtonGroup>
    <ButtonGroupText render={<Label htmlFor="amount" />}>$</ButtonGroupText>
    <TextField id="amount" aria-label="Amount" placeholder="10.00" className="w-32" />
    <ButtonGroupText>USD</ButtonGroupText>
  </ButtonGroup>

  ```jsx
  <ButtonGroup>
    <ButtonGroupText render={<Label htmlFor="amount" />}>$</ButtonGroupText>
    <TextField id="amount" aria-label="Amount" placeholder="10.00" className="w-32" />
    <ButtonGroupText>USD</ButtonGroupText>
  </ButtonGroup>
  ```
</Example>

## Nested groups

Nested button groups receive spacing while the actions inside each nested group remain connected.

<Example direction="row" minHeight="160px">
  <ButtonGroup aria-label="History and clipboard actions">
    <ButtonGroup>
      <Button variant="outline" aria-label="Undo">
        <Icon size="sm"><Lucide.Undo2 /></Icon>
      </Button>
      <Button variant="outline" aria-label="Redo">

      </Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline" aria-label="Cut">

      </Button>
      <Button variant="outline" aria-label="Copy">
        <Icon size="sm"><Lucide.Copy /></Icon>
