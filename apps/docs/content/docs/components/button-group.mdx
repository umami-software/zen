import {
  Button,
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
  Example,
  Input,
  Label,
  Lucide,
} from '../../../mdx-components';

A container that groups related buttons together with consistent styling. Label each group with
`aria-label` or `aria-labelledby`.

<Example direction="row" minHeight="160px">
  <ButtonGroup aria-label="Inbox actions">
    <ButtonGroup>
      <Button variant="outline" size="icon" aria-label="Go back">
        <Lucide.ArrowLeft />
      </Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Archive</Button>
      <Button variant="outline">Report</Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Snooze</Button>
      <DropdownMenu>
        <DropdownMenuTrigger render={<Button variant="outline" size="icon" aria-label="More options" />}>
          <Lucide.MoreHorizontal />
        </DropdownMenuTrigger>
        <DropdownMenuContent align="end">
          <DropdownMenuGroup>
            <DropdownMenuItem>Mark as read</DropdownMenuItem>
            <DropdownMenuItem>Archive</DropdownMenuItem>
          </DropdownMenuGroup>
          <DropdownMenuSeparator />
          <DropdownMenuGroup>
            <DropdownMenuItem>Add to calendar</DropdownMenuItem>
            <DropdownMenuItem variant="destructive">Trash</DropdownMenuItem>
          </DropdownMenuGroup>
        </DropdownMenuContent>
      </DropdownMenu>
    </ButtonGroup>
  </ButtonGroup>

  ```jsx
  <ButtonGroup aria-label="Inbox actions">
    <ButtonGroup>
      <Button variant="outline" size="icon" aria-label="Go back">
        <Lucide.ArrowLeft />
      </Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Archive</Button>
      <Button variant="outline">Report</Button>
    </ButtonGroup>
    <ButtonGroup>
      <Button variant="outline">Snooze</Button>
      <DropdownMenu>
        <DropdownMenuTrigger render={<Button variant="outline" size="icon" aria-label="More options" />}>
          <Lucide.MoreHorizontal />
        </DropdownMenuTrigger>
        <DropdownMenuContent align="end">
          <DropdownMenuGroup>
            <DropdownMenuItem>Mark as read</DropdownMenuItem>
            <DropdownMenuItem>Archive</DropdownMenuItem>
          </DropdownMenuGroup>
          <DropdownMenuSeparator />
          <DropdownMenuGroup>
            <DropdownMenuItem>Add to calendar</DropdownMenuItem>
            <DropdownMenuItem variant="destructive">Trash</DropdownMenuItem>
          </DropdownMenuGroup>
        </DropdownMenuContent>
      </DropdownMenu>
    </ButtonGroup>
  </ButtonGroup>
  ```
</Example>

Use `ButtonGroup` for actions. Use `ToggleGroup` when the buttons represent a selected state.

## Separator

`ButtonGroupSeparator` divides buttons that have no border of their own, such as `secondary`.
Outline buttons don't need one.

<Example direction="row" minHeight="160px">
  <ButtonGroup aria-label="Clipboard actions">
    <Button variant="secondary" size="sm">Copy</Button>
    <ButtonGroupSeparator />
    <Button variant="secondary" size="sm">Paste</Button>
  </ButtonGroup>

  ```jsx
  <ButtonGroup aria-label="Clipboard actions">
    <Button variant="secondary" size="sm">Copy</Button>
    <ButtonGroupSeparator />
    <Button variant="secondary" size="sm">Paste</Button>
  </ButtonGroup>
  ```
</Example>

## Input and text

`ButtonGroupText` adds non-interactive content. Use its `render` prop when the text needs different
semantics, such as a label. Inputs stretch to fill the group.

<Example direction="row" minHeight="160px">
  <ButtonGroup>
    <ButtonGroupText render={<Label htmlFor="amount" />}>$</ButtonGroupText>
    <Input id="amount" placeholder="10.00" />
    <ButtonGroupText>USD</ButtonGroupText>
  </ButtonGroup>
  <ButtonGroup>
    <Input placeholder="Search..." aria-label="Search" />
    <Button variant="outline" size="icon" aria-label="Search">
      <Lucide.Search />
    </Button>
  </ButtonGroup>

  ```jsx
  <ButtonGroup>
    <ButtonGroupText render={<Label htmlFor="amount" />}>$</ButtonGroupText>
    <Input id="amount" placeholder="10.00" />
    <ButtonGroupText>USD</ButtonGroupText>
  </ButtonGroup>
  <ButtonGroup>
    <Input placeholder="Search..." aria-label="Search" />
    <Button variant="outline" size="icon" aria-label="Search">
      <Lucide.Search />
    </Button>
  </ButtonGroup>
  ```
</Example>
