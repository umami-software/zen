Status lights are used to color code categories and labels commonly found in data visualization.

<Example>
  <StatusLight>Status</StatusLight>

  ```jsx
  <StatusLight>Status</StatusLight>
  ```
</Example>

## Variants

The variants use the theme's `success`, `warning`, `destructive` and `info` tokens.

<Example direction="column">
  <StatusLight variant="success">Success</StatusLight>
  <StatusLight variant="warning">Warning</StatusLight>
  <StatusLight variant="destructive">Destructive</StatusLight>
  <StatusLight variant="info">Info</StatusLight>
  <StatusLight variant="muted">Muted</StatusLight>

  ```jsx
  <StatusLight variant="success">Success</StatusLight>
  <StatusLight variant="warning">Warning</StatusLight>
  <StatusLight variant="destructive">Destructive</StatusLight>
  <StatusLight variant="info">Info</StatusLight>
  <StatusLight variant="muted">Muted</StatusLight>
  ```
</Example>

## Custom color

<Example direction="column">
  <StatusLight color="#8b5cf6">Purple</StatusLight>
  <StatusLight color="var(--chart-2)">Chart 2</StatusLight>

  ```jsx
  <StatusLight color="#8b5cf6">Purple</StatusLight>
  <StatusLight color="var(--chart-2)">Chart 2</StatusLight>
  ```
</Example>
