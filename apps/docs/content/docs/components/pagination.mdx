Pagination with page navigation, next and previous links. The parts are presentational: you render
the links and decide which page each one points to. `PaginationLink` renders an `a` styled as a
`Button`, and `isActive` marks the current page.

## Controlled

For client-side paging, keep the page in state and handle `onClick` on each link. This example
also disables Previous and Next at the ends.

<Example>
  <PaginationExample />

  ```jsx
  const [page, setPage] = useState(1);

  const go = next => event => {
    event.preventDefault();
    setPage(Math.min(Math.max(next, 1), pageCount));
  };

  <Pagination>
    <PaginationContent>
      <PaginationItem>
        <PaginationPrevious
          href="#"
          onClick={go(page - 1)}
          aria-disabled={page === 1}
          className={page === 1 ? 'pointer-events-none opacity-50' : undefined}
        />
      </PaginationItem>
      {pages.map((value, index) =>
        value === null ? (
          <PaginationItem key={`ellipsis-${index}`}>
            <PaginationEllipsis />
          </PaginationItem>
        ) : (
          <PaginationItem key={value}>
            <PaginationLink href="#" isActive={value === page} onClick={go(value)}>
              {value}
            </PaginationLink>
          </PaginationItem>
        ),
      )}
      <PaginationItem>
        <PaginationNext
          href="#"
          onClick={go(page + 1)}
          aria-disabled={page === pageCount}
          className={page === pageCount ? 'pointer-events-none opacity-50' : undefined}
        />
      </PaginationItem>
    </PaginationContent>
  </Pagination>
  ```
</Example>

## Links

`PaginationLink` spreads its props onto the `a`, so for server-rendered paging pass the URL of each
page as `href`.

```jsx
<PaginationItem>
  <PaginationLink href="/posts?page=2" isActive>
    2
  </PaginationLink>
</PaginationItem>
```
