## Colors

`color` takes a theme token name or a Tailwind palette color.

<Example direction="row" gap="4">

    <Lucide.CircleCheck />
  </Icon>
  <Icon size="lg" color="success">

  <Icon size="lg" color="destructive">

## Fill and stroke colors

Control SVG fill and stroke colors using the `fillColor` and `strokeColor` props.

<Example direction="row" gap="4">
  <Icon size="lg" fillColor="blue-500">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" strokeColor="red-500" strokeWidth="2">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" fillColor="green-500" strokeColor="green-700" strokeWidth="1">
    <Lucide.Heart />
  </Icon>

  ```jsx
  <Icon size="lg" fillColor="blue-500">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" strokeColor="red-500" strokeWidth="2">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" fillColor="green-500" strokeColor="green-700" strokeWidth="1">
    <Lucide.Heart />
  </Icon>
  ```
</Example>

## Component props

  <PropertiesTable.Row name="size" type="IconSize">"xs" | "sm" | "md" | "lg" | "xl" (default: the theme's `--icon-size`, 14px)</PropertiesTable.Row>
  <PropertiesTable.Row name="color" type="FontColor">Icon color: a theme token (`foreground`, `muted`, `primary`, `destructive`, `success`, ...) or a Tailwind color (`blue`, `blue-500`)</PropertiesTable.Row>
  <PropertiesTable.Row name="rotate" type="number">Rotation in degrees</PropertiesTable.Row>
  <PropertiesTable.Row name="strokeWidth" type="StrokeWidth">"0.5" | "1" | "1.5" | "2" | "3" | "4"</PropertiesTable.Row>
  <PropertiesTable.Row name="strokeColor" type="StrokeColor">SVG stroke color (theme token or Tailwind color)</PropertiesTable.Row>
  <PropertiesTable.Row name="fillColor" type="FillColor">SVG fill color (theme token or Tailwind color)</PropertiesTable.Row>
</PropertiesTable>
