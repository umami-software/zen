## Fill and stroke colors

Control SVG fill and stroke colors using the `fillColor` and `strokeColor` props.

<Example direction="row" gap="4">
  <Icon size="lg" fillColor="blue-500">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" strokeColor="red-500" strokeWidth="2">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" fillColor="green-500" strokeColor="green-700" strokeWidth="1">
    <Lucide.Heart />
  </Icon>

  ```jsx
  <Icon size="lg" fillColor="blue-500">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" strokeColor="red-500" strokeWidth="2">
    <Lucide.Heart />
  </Icon>
  <Icon size="lg" fillColor="green-500" strokeColor="green-700" strokeWidth="1">
    <Lucide.Heart />
  </Icon>
  ```
</Example>

## Component props

<PropertiesTable>
  <ResponseField name="size" type="IconSize">"xs" | "sm" | "md" | "lg" | "xl" (default: "sm")</ResponseField>
  <ResponseField name="color" type="FontColor">Icon color</ResponseField>
  <ResponseField name="rotate" type="number">Rotation in degrees</ResponseField>
  <ResponseField name="strokeWidth" type="StrokeWidth">"0.5" | "1" | "1.5" | "2" | "3" | "4"</ResponseField>
  <ResponseField name="strokeColor" type="StrokeColor">SVG stroke color (semantic, Tailwind color, or color-shade)</ResponseField>
  <ResponseField name="fillColor" type="FillColor">SVG fill color (semantic, Tailwind color, or color-shade)</ResponseField>
</PropertiesTable>
