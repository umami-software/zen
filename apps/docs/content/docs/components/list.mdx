      <ListItem>Five</ListItem>

  <List>
    <ListItem>One</ListItem>

## Controlled

The selection is always a `string[]`, also in single selection mode.

```jsx
const [value, setValue] = useState(['two']);

<List selectionMode="single" value={value} onValueChange={setValue}>
  <ListItem value="one">One</ListItem>
  <ListItem value="two">Two</ListItem>
  <ListItem value="three">Three</ListItem>
</List>
```

## Component props

### List

<PropertiesTable>
  <PropertiesTable.Row name="label" type="ReactNode">Label displayed above the list</PropertiesTable.Row>
  <PropertiesTable.Row name="selectionMode" type="string">"none" | "single" | "multiple" (default: "none")</PropertiesTable.Row>
  <PropertiesTable.Row name="value" type="string[]">Controlled selected item values</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultValue" type="string[]">Initially selected item values</PropertiesTable.Row>
  <PropertiesTable.Row name="onValueChange" type="(value: string[]) => void">Called with the selected item values whenever the selection changes</PropertiesTable.Row>
  <PropertiesTable.Row name="showCheckmark" type="boolean">Shows a check mark on selected items (default: true)</PropertiesTable.Row>
</PropertiesTable>

The list uses a roving tabindex: the listbox itself is the single tab stop,
<kbd>ArrowUp</kbd>/<kbd>ArrowDown</kbd>/<kbd>Home</kbd>/<kbd>End</kbd> move focus between options,
and <kbd>Enter</kbd>/<kbd>Space</kbd> toggles the focused option.
