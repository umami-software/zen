import { Box, Example, NumberField } from '../../../mdx-components';

A number field allows a user to enter a numeric value with stepper buttons for incrementing and
decrementing. It is built on Base UI's `NumberField`.

<Example>
  <Box width="200px"><NumberField label="Quantity" defaultValue={1} /></Box>

  ```jsx
  <NumberField label="Quantity" defaultValue={1} />
  ```
</Example>

## Min, max, and step

<Example>
  <Box width="200px"><NumberField label="Percent" defaultValue={50} min={0} max={100} step={10} /></Box>

  ```jsx
  <NumberField label="Percent" defaultValue={50} min={0} max={100} step={10} />
  ```
</Example>

## Format

Values are formatted with `Intl.NumberFormat` using the `format` prop.

<Example>
  <Box width="200px"><NumberField label="Price" defaultValue={25} format={{ style: 'currency', currency: 'USD' }} /></Box>

  ```jsx
  <NumberField
    label="Price"
    defaultValue={25}
    format={{ style: 'currency', currency: 'USD' }}
  />
  ```
</Example>

## Disabled

<Example>
  <Box width="200px"><NumberField label="Quantity" defaultValue={1} disabled /></Box>

  ```jsx
  <NumberField label="Quantity" defaultValue={1} disabled />
  ```
</Example>

## Controlled

```jsx
const [value, setValue] = useState(1);

<NumberField label="Quantity" value={value} onValueChange={setValue} />
```

## Component props

Other Base UI `NumberField.Root` props (`name`, `locale`, `largeStep`, `smallStep`, …) are passed through.

  <PropertiesTable.Row name="label" type="ReactNode">Label displayed above the field</PropertiesTable.Row>
