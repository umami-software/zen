import { Alert, AlertDescription, AlertTitle, Box, DataColumn, DataTable, Example, Lucide, ZenProvider } from '../../../mdx-components';

<ZenProvider>

Displays a callout for user attention. Compose an `Alert` from an optional icon,
an `AlertTitle`, and an `AlertDescription`.

<Example>
  <Box width="448px" maxWidth="100%">
    <Alert>
      <Lucide.Terminal />
      <AlertTitle>Heads up!</AlertTitle>
      <AlertDescription>
        You can add components to your app using the CLI.
      </AlertDescription>
    </Alert>
  </Box>

  ```jsx
  <Alert>
    <Lucide.Terminal />
    <AlertTitle>Heads up!</AlertTitle>
    <AlertDescription>You can add components to your app using the CLI.</AlertDescription>
  </Alert>
  ```
</Example>

## Danger

Use `variant="danger"` for errors and dangerous or failed operations.

<Example>
  <Box width="448px" maxWidth="100%">
    <Alert variant="danger">
      <Lucide.CircleAlert />
      <AlertTitle>Payment failed</AlertTitle>
      <AlertDescription>
        Your payment could not be processed. Please check your payment method and try again.
      </AlertDescription>
    </Alert>
  </Box>

  ```jsx
  <Alert variant="danger">
    <Lucide.CircleAlert />
    <AlertTitle>Payment failed</AlertTitle>
    <AlertDescription>
      Your payment could not be processed. Please check your payment method and try again.
    </AlertDescription>
  </Alert>
  ```
</Example>

## Without icon

Icons are optional children — omit the icon and the content spans the full width.

<Example>
  <Box width="448px" maxWidth="100%">
    <Alert>
      <AlertTitle>Scheduled maintenance</AlertTitle>
      <AlertDescription>
        The service will be unavailable on Sunday from 2–4 AM UTC.
      </AlertDescription>
    </Alert>
  </Box>

  ```jsx
  <Alert>
    <AlertTitle>Scheduled maintenance</AlertTitle>
    <AlertDescription>The service will be unavailable on Sunday from 2–4 AM UTC.</AlertDescription>
  </Alert>
  ```
</Example>

## Component props

### Alert

<Example>
  <DataTable
    data={[
      { name: 'variant', value: "'default' | 'danger'", description: 'Visual style (default: "default")' },
      { name: 'children', value: 'ReactNode', description: 'An optional svg icon, AlertTitle, and AlertDescription' },
    ]}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="value" label="Type" />
    <DataColumn id="description" label="Description" />
  </DataTable>
</Example>

`Alert`, `AlertTitle`, and `AlertDescription` all accept standard `div` props
including `className`, and expose `data-slot="alert"`, `data-slot="alert-title"`,
and `data-slot="alert-description"` attributes for styling.
