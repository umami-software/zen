A horizontal row of menus, like the menu bar at the top of a desktop application. Once one menu is
open, hovering or using the arrow keys moves between menus. Each menu uses the same items as
`DropdownMenu`.

## Parts

- `Menubar` is the root bar. `MenubarMenu` is one menu in it.
- `MenubarTrigger` is the button that opens a menu. `MenubarContent` is the popup.
- `MenubarItem`, `MenubarCheckboxItem`, `MenubarRadioGroup` and `MenubarRadioItem` are the items. Set `inset` to line plain items up with checkbox and radio items.
- `MenubarGroup` and `MenubarLabel` group and label items. A label must be inside a group.
- `MenubarSub`, `MenubarSubTrigger` and `MenubarSubContent` build a submenu.
- `MenubarSeparator` and `MenubarShortcut` add a divider and a shortcut hint.

The item props are the same as for [Dropdown Menu](/docs/components/dropdown-menu).

## Component props

### Menubar

<PropertiesTable>
  <PropertiesTable.Row name="orientation" type="string">"horizontal" | "vertical" (default: "horizontal")</PropertiesTable.Row>
  <PropertiesTable.Row name="loopFocus" type="boolean">Wraps keyboard focus at the ends of the bar (default: true)</PropertiesTable.Row>
  <PropertiesTable.Row name="modal" type="boolean">Locks page scroll while a menu is open (default: true)</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Disables every menu in the bar</PropertiesTable.Row>
</PropertiesTable>

### MenubarMenu

<PropertiesTable>
  <PropertiesTable.Row name="open" type="boolean">Controlled open state of this menu</PropertiesTable.Row>
  <PropertiesTable.Row name="onOpenChange" type="(open, eventDetails) => void">Called when this menu opens or closes</PropertiesTable.Row>
</PropertiesTable>
