import { Box, Example, Slider } from '../../../mdx-components';

An input where the user selects a value from within a given range. The slider renders one thumb
per value, so pass an array to get a range.

<Example>
  <Box width="320px" maxWidth="100%">
    <Slider defaultValue={[75]} max={100} step={1} />
  </Box>

  ```jsx
  <Slider defaultValue={[75]} max={100} step={1} />
  ```
</Example>

## Range

Two values render two thumbs.

<Example>
  <Box width="320px" maxWidth="100%">
    <Slider defaultValue={[25, 50]} max={100} step={5} />
  </Box>

  ```jsx
  <Slider defaultValue={[25, 50]} max={100} step={5} />
  ```
</Example>

## Controlled

`onValueChange` fires while dragging; `onValueCommitted` fires once the user releases the thumb.

```jsx
const [value, setValue] = useState([0.3, 0.7]);

<Slider value={value} onValueChange={setValue} min={0} max={1} step={0.1} />
```
