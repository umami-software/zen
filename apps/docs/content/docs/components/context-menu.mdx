Displays a menu of actions at the pointer when the user right clicks an area, or long presses it on
touch devices. It uses the same items as `DropdownMenu`.

## Parts

- `ContextMenu` is the root. `ContextMenuTrigger` is the area that opens the menu.
- `ContextMenuContent` is the popup.
- `ContextMenuItem` is an action. Set `variant="destructive"` for dangerous actions and `inset` to align it with checkbox and radio items.
- `ContextMenuCheckboxItem`, `ContextMenuRadioGroup` and `ContextMenuRadioItem` hold a selected state.
- `ContextMenuGroup` groups items. `ContextMenuLabel` labels a group and must be inside one.
- `ContextMenuSub`, `ContextMenuSubTrigger` and `ContextMenuSubContent` build a submenu.
- `ContextMenuSeparator` and `ContextMenuShortcut` add a divider and a shortcut hint.

</PropertiesTable>

### ContextMenuItem

<PropertiesTable>
  <PropertiesTable.Row name="onClick" type="(event) => void">Called when the item is chosen</PropertiesTable.Row>
  <PropertiesTable.Row name="variant" type="string">"default" | "destructive" (default: "default")</PropertiesTable.Row>
  <PropertiesTable.Row name="inset" type="boolean">Adds left padding to line up with checkbox and radio items</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Disables the item</PropertiesTable.Row>
  <PropertiesTable.Row name="closeOnClick" type="boolean">Closes the menu when the item is chosen (default: true)</PropertiesTable.Row>
</PropertiesTable>

### ContextMenuCheckboxItem

<PropertiesTable>
  <PropertiesTable.Row name="checked" type="boolean">Controlled checked state</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultChecked" type="boolean">Initial checked state when uncontrolled</PropertiesTable.Row>
  <PropertiesTable.Row name="onCheckedChange" type="(checked, eventDetails) => void">Called when the item is toggled</PropertiesTable.Row>
</PropertiesTable>

<PropertiesTable>

  <PropertiesTable.Row name="onValueChange" type="(value, eventDetails) => void">Called when the selection changes</PropertiesTable.Row>
</PropertiesTable>
