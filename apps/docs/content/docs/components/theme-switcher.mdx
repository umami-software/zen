A segmented control that allows users to choose between light, dark, or system theme.

<Example>
  <ThemeSwitcher />

  ```jsx
  <ThemeSwitcher />
  ```
</Example>

## Features

- Shows all three options (light, dark, system) at once
- Highlights the currently selected option
- Persists the mode preference to localStorage
- Automatically responds to system theme changes when "system" is selected
