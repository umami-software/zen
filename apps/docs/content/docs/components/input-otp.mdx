Accessible one-time password component with copy paste functionality, built on
[input-otp](https://github.com/guilhermerodz/input-otp). Set the number of characters with
`maxLength` and render one `InputOTPSlot` per character.

<Example>
  <InputOTP maxLength={6}>
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
    </InputOTPGroup>
    <InputOTPSeparator />
    <InputOTPGroup>
      <InputOTPSlot index={3} />
      <InputOTPSlot index={4} />
      <InputOTPSlot index={5} />
    </InputOTPGroup>
  </InputOTP>

  ```jsx
  <InputOTP maxLength={6}>
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
    </InputOTPGroup>
    <InputOTPSeparator />
    <InputOTPGroup>
      <InputOTPSlot index={3} />
      <InputOTPSlot index={4} />
      <InputOTPSlot index={5} />
    </InputOTPGroup>
  </InputOTP>
  ```
</Example>

## Pattern

`pattern` restricts the accepted characters. The `input-otp` package exports
`REGEXP_ONLY_DIGITS`, `REGEXP_ONLY_CHARS` and `REGEXP_ONLY_DIGITS_AND_CHARS`.

<Example>
  <InputOTP maxLength={4} pattern="^\d+$">
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
      <InputOTPSlot index={3} />
    </InputOTPGroup>
  </InputOTP>

  ```jsx
  <InputOTP maxLength={4} pattern="^\d+$">
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
      <InputOTPSlot index={3} />
    </InputOTPGroup>
  </InputOTP>
  ```
</Example>

## Controlled

`onChange` receives the new string value. `onComplete` fires once every slot is filled.

<Example>
  <InputOTPExample />

  ```jsx
  const [value, setValue] = useState('');

  <InputOTP maxLength={6} value={value} onChange={setValue}>
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />
      <InputOTPSlot index={3} />
      <InputOTPSlot index={4} />
      <InputOTPSlot index={5} />
    </InputOTPGroup>
  </InputOTP>
  <Text size="sm" color="muted-foreground">
    {value === '' ? 'Enter your one-time password.' : `You entered: ${value}`}
  </Text>
  ```
</Example>
