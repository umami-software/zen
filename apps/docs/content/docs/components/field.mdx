Combine labels, controls and help text to compose accessible form fields. The field parts handle
layout only, so connect a `FieldLabel` to its control with `htmlFor` and `id`. To bind fields to
form state and validation, use `Form` and `FormField`.

<Example>
  <Box width="300px" maxWidth="100%">
    <Field>
      <FieldLabel htmlFor="email">Email</FieldLabel>
      <Input id="email" type="email" placeholder="ada@example.com" />
      <FieldDescription>We will never share your address.</FieldDescription>
    </Field>
  </Box>

  ```jsx
  <Field>
    <FieldLabel htmlFor="email">Email</FieldLabel>
    <Input id="email" type="email" placeholder="ada@example.com" />
    <FieldDescription>We will never share your address.</FieldDescription>
  </Field>
  ```
</Example>

## Error message

Set `data-invalid` on `Field` to color the label, and `aria-invalid` on the control. `FieldError`
renders with `role="alert"`. It also accepts an `errors` array, such as the errors from a form
library.

<Example>
  <Box width="300px" maxWidth="100%">
    <Field data-invalid>
      <FieldLabel htmlFor="username">Username</FieldLabel>
      <Input id="username" defaultValue="ada" aria-invalid />
      <FieldError>That username is already taken.</FieldError>
    </Field>
  </Box>

  ```jsx
  <Field data-invalid>
    <FieldLabel htmlFor="username">Username</FieldLabel>
    <Input id="username" defaultValue="ada" aria-invalid />
    <FieldError>That username is already taken.</FieldError>
  </Field>
  ```
</Example>

## Horizontal orientation

Use `orientation="horizontal"` for checkboxes and switches, and `FieldContent` to stack a label and
description next to the control.

<Example>
  <Box width="400px" maxWidth="100%">
    <FieldGroup>
      <Field orientation="horizontal">
        <Checkbox id="mentions" defaultChecked />
        <FieldContent>
          <FieldLabel htmlFor="mentions">Email notifications</FieldLabel>
          <FieldDescription>Get notified when someone mentions you.</FieldDescription>
        </FieldContent>
      </Field>
      <Field orientation="horizontal">
        <FieldContent>
          <FieldLabel htmlFor="marketing">Marketing emails</FieldLabel>
          <FieldDescription>Receive news about products and features.</FieldDescription>
        </FieldContent>
        <Switch id="marketing" />
      </Field>
    </FieldGroup>
  </Box>

  ```jsx
  <FieldGroup>
    <Field orientation="horizontal">
      <Checkbox id="mentions" defaultChecked />
      <FieldContent>
        <FieldLabel htmlFor="mentions">Email notifications</FieldLabel>

      </FieldContent>
  ```

## Field group

`FieldGroup` stacks fields, and `FieldSeparator` divides them, with an optional label.

<Example>
  <Box width="300px" maxWidth="100%">
    <FieldGroup>
      <Field>
        <FieldLabel htmlFor="first-name">First name</FieldLabel>
        <Input id="first-name" placeholder="Ada" />
      </Field>
      <Field>
        <FieldLabel htmlFor="last-name">Last name</FieldLabel>
        <Input id="last-name" placeholder="Lovelace" />
      </Field>
      <FieldSeparator>Optional</FieldSeparator>
      <Field>
        <FieldLabel htmlFor="company">Company</FieldLabel>
        <Input id="company" placeholder="Analytical Engines Ltd" />
      </Field>
    </FieldGroup>
  </Box>

  ```jsx
  <FieldGroup>
    <Field>
      <FieldLabel htmlFor="first-name">First name</FieldLabel>
      <Input id="first-name" placeholder="Ada" />
    </Field>
    <Field>

      <Input id="last-name" placeholder="Lovelace" />

    <FieldSeparator>Optional</FieldSeparator>
    <Field>

    </Field>
  ```

## Fieldset

`FieldSet` renders a `fieldset` with a `FieldLegend` and an optional description.

<Example>

        <Field>
          <FieldLabel htmlFor="city">City</FieldLabel>
          <Input id="city" placeholder="London" />

## Parts

- `Field` wraps one control with its label, description and error.
- `FieldLabel` is a `label`. `FieldTitle` is a non-label heading for a field.
- `FieldDescription` is help text. `FieldError` is a validation message.
- `FieldContent` stacks a label and description, for horizontal fields.
- `FieldGroup` stacks several fields. `FieldSeparator` divides them.
- `FieldSet` and `FieldLegend` group related fields under a legend.
