import { Box, Example, Meter } from '../../../mdx-components';

A meter represents a measured value within a known range, such as disk usage or battery level. It is
built on Base UI's `Meter`.

<Example>
  <Box width="300px"><Meter label="Storage used" value={60} showValue /></Box>

  ```jsx
  <Meter label="Storage used" value={60} showValue />
  ```
</Example>

## Custom range

<Example>
  <Box width="300px"><Meter label="Battery" value={2500} min={0} max={5000} showValue /></Box>

  ```jsx
  <Meter label="Battery" value={2500} min={0} max={5000} showValue />
  ```
</Example>

## Format

Values are formatted with `Intl.NumberFormat` using the `format` prop.

<Example>
  <Box width="300px"><Meter label="Memory" value={35} showValue format={{ style: 'unit', unit: 'percent' }} /></Box>

  ```jsx
  <Meter
    label="Memory"
    value={35}
    showValue
    format={{ style: 'unit', unit: 'percent' }}
  />
  ```
</Example>

## Component props

Other Base UI `Meter.Root` props (`locale`, `getAriaValueText`, …) are passed through.
