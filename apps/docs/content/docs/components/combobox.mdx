A combo box combines a text input with a listbox, allowing users to filter a list of options to items matching a query.

<Example>
  <ComboBox>
    <ListItem id="one">One</ListItem>
    <ListItem id="two">Two</ListItem>
    <ListItem id="three">Three</ListItem>
    <ListItem id="four">Four</ListItem>
    <ListItem id="five">Five</ListItem>
    <ListItem id="six">Six</ListItem>
    <ListItem id="seven">Seven</ListItem>
    <ListItem id="eight">Eight</ListItem>
    <ListItem id="nine">Nine</ListItem>
    <ListItem id="ten">Ten</ListItem>
  </ComboBox>

  ```jsx
  <ComboBox>
    <ListItem id="one">One</ListItem>
    <ListItem id="two">Two</ListItem>
    <ListItem id="three">Three</ListItem>
    <ListItem id="four">Four</ListItem>
    <ListItem id="five">Five</ListItem>
  </ComboBox>
  ```
</Example>

## Empty state

When filtering returns no matches, the combo box displays a helpful empty state. Use `emptyState`
to replace it with custom content (`renderEmptyState` is still supported but deprecated).

<Example>
  <ComboBoxEmptyExample />

  ```jsx
  <ComboBox
    items={['One', 'Two', 'Three']}
    renderEmptyState={() => <Text color="muted">Nothing matched your search.</Text>}
  />
  ```
</Example>

## Anatomy

Items are handed to Base UI as `{ label, value }` objects, so filtering and label resolution happen
inside the primitive. The rendered parts expose `data-slot` attributes: `combobox`,
`combobox-input`, `combobox-clear`, `combobox-trigger`, `combobox-positioner`, `combobox-content`,
and `combobox-empty`.
