An input combined with a list of suggestions that filters as the user types. Pass the options to
`items` on the root and render each one from the `ComboboxList` render function.

<Example>
  <Combobox items={['Next.js', 'SvelteKit', 'Nuxt', 'Remix', 'Astro']}>
    <ComboboxInput placeholder="Select a framework" />
    <ComboboxContent>
      <ComboboxEmpty>No items found.</ComboboxEmpty>
      <ComboboxList>
        {(item) => (
          <ComboboxItem key={item} value={item}>
            {item}
          </ComboboxItem>
        )}
      </ComboboxList>
    </ComboboxContent>
  </Combobox>

## Multiple

Set `multiple` and render the selected values as chips with `ComboboxChips`. Pass the chips
container as the popup `anchor` so the list lines up with it.

<Example>
  <ComboboxMultipleExample />

  ```jsx
  function ComboboxMultipleExample() {
    const anchor = useComboboxAnchor();

    return (
      <Combobox multiple autoHighlight items={frameworks} defaultValue={[frameworks[0]]}>
        <ComboboxChips ref={anchor} className="w-full max-w-xs">
          <ComboboxValue>
            {(values) => (
              <>
                {values.map(value => (
                  <ComboboxChip key={value}>{value}</ComboboxChip>
                ))}
                <ComboboxChipsInput placeholder="Add framework" />
              </>
            )}
          </ComboboxValue>
        </ComboboxChips>
        <ComboboxContent anchor={anchor}>
          <ComboboxEmpty>No items found.</ComboboxEmpty>
          <ComboboxList>
            {(item) => (
              <ComboboxItem key={item} value={item}>
                {item}
              </ComboboxItem>
            )}
          </ComboboxList>
        </ComboboxContent>
      </Combobox>
    );
  }
  ```
</Example>

## Empty state

`ComboboxEmpty` is shown when nothing matches. Control the query with `inputValue` and
`onInputValueChange` to mention it in the message.

<Example>
  <ComboBoxEmptyExample />

  ```jsx
  function ComboBoxEmptyExample() {
    const [query, setQuery] = useState('');

    return (
      <Combobox items={fruits} inputValue={query} onInputValueChange={setQuery}>
        <ComboboxInput placeholder="Search fruit..." />
        <ComboboxContent>
          <ComboboxEmpty>No fruit matches "{query}".</ComboboxEmpty>
          <ComboboxList>
            {(item) => (
              <ComboboxItem key={item} value={item}>
                {item}
              </ComboboxItem>
            )}
          </ComboboxList>
        </ComboboxContent>
      </Combobox>
    );
  }
  ```
</Example>

## Parts

- `Combobox` is the root. It holds the items, the value and the query.
- `ComboboxInput` is the text input, with an optional trigger button (`showTrigger`) and clear button (`showClear`).
- `ComboboxContent` is the popup. `ComboboxList` renders the filtered items, and `ComboboxEmpty` shows when there are none.
- `ComboboxItem` is one option, identified by `value`.
- `ComboboxGroup`, `ComboboxLabel`, `ComboboxCollection` and `ComboboxSeparator` group items.
- `ComboboxChips`, `ComboboxChip`, `ComboboxChipsInput` and `ComboboxValue` render multiple selections. `useComboboxAnchor` creates the anchor ref.
- `ComboboxTrigger` opens the popup from a custom control.

### ComboboxInput

<PropertiesTable>
  <PropertiesTable.Row name="showTrigger" type="boolean">Shows the chevron button that opens the popup (default: true)</PropertiesTable.Row>

  <PropertiesTable.Row name="disabled" type="boolean">Disables the input and its buttons</PropertiesTable.Row>

### ComboboxContent
