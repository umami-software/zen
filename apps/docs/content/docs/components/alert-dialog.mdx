A modal dialog that interrupts the user with important content and expects a response. Unlike a
`Dialog`, it can't be dismissed by clicking outside.

`AlertDialogCancel` closes the dialog. `AlertDialogAction` is a plain `Button` and does not close it
on its own, so control the dialog with `open` and `onOpenChange` and close it once the action is
done. For simple confirmations, `ConfirmationDialog` wires this up for you.

<Example>
  <AlertDialogExample />

  ```jsx
  function AlertDialogExample() {
    const [open, setOpen] = useState(false);

    const handleDelete = () => {
      // Delete the account, then close the dialog.
      setOpen(false);
    };

    return (
      <AlertDialog open={open} onOpenChange={setOpen}>
        <AlertDialogTrigger render={<Button variant="destructive" />}>
          Delete account
        </AlertDialogTrigger>
        <AlertDialogContent>
          <AlertDialogHeader>
            <AlertDialogTitle>Delete your account?</AlertDialogTitle>
            <AlertDialogDescription>
              This cannot be undone. Your account and all of its data will be permanently deleted.
            </AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter>
            <AlertDialogCancel>Cancel</AlertDialogCancel>
            <AlertDialogAction variant="destructive" onClick={handleDelete}>
              Delete
            </AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </AlertDialog>
    );
  }
  ```
</Example>

## Small with media

Set `size="sm"` on `AlertDialogContent` for a compact, centered layout, and add an icon with
`AlertDialogMedia`.

## Parts

- `AlertDialog` is the root. It holds the open state.
- `AlertDialogTrigger` opens the dialog. Use `render={<Button />}` to style it.
- `AlertDialogContent` is the popup, rendered in a portal with a backdrop.
- `AlertDialogHeader`, `AlertDialogTitle`, `AlertDialogDescription` and `AlertDialogMedia` make up the header.
- `AlertDialogFooter` holds `AlertDialogCancel` (closes the dialog) and `AlertDialogAction`.
