import { Box, Column, Dots, Example, Label, Loading, Row, Spinner } from '../../../mdx-components';

An element that indicates content is loading. `Loading` renders a `status` region containing either
Zen's `Spinner` or its animated `Dots`.

<Example>
  <Loading />

  ```jsx
  <Loading />
  ```
</Example>

## Icons

<Example>
  <Row gap="6" alignItems="center">
    <Loading icon="spinner" />
    <Loading icon="dots" />

  ```jsx
  <Loading icon="spinner" />
  <Loading icon="dots" />
  ```
</Example>

## Placement

`placement="absolute"` centers the indicator over its nearest positioned parent.

<Example>
  <Box position="relative" width="300px" height="160px" border borderRadius>
    <Loading placement="absolute" size="lg" />
  </Box>

  ```jsx
  <Box position="relative" width="300px" height="160px" border borderRadius>
    <Loading placement="absolute" size="lg" />
  </Box>
  ```
</Example>

## Spinner and Dots

The indicators can also be used on their own. `Spinner` is an arc that grows and shrinks as it
rotates over a faint track. It has the same API as shadcn's `Spinner`: an `svg` sized with a `size-*`
class (default `size-4`) and drawn in the current text color. Set `quiet` to hide the track.

<Example>
  <Row gap="6" alignItems="center">
    <Spinner />
    <Spinner className="size-6" />
    <Spinner className="size-6" quiet />
    <Dots />
  </Row>

  ```jsx
  <Spinner />
  <Spinner className="size-6" />
  <Spinner className="size-6" quiet />
  <Dots />
  ```
</Example>
