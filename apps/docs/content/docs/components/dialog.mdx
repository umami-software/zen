A window overlaid on the primary window, rendering the content underneath inert. `Dialog` is a
modal: it traps focus, locks page scrolling, and closes on Escape or a click outside.

For panels that slide in from an edge of the screen use `Sheet`, and for swipeable panels use
`Drawer`. For confirmations that need an explicit answer use `AlertDialog`.

## Controlled

Pass `open` and `onOpenChange` to close the dialog from your own code, for example after a form is
submitted.

<Example>
  <DialogExample />

  ```jsx
  function DialogExample() {
    const [open, setOpen] = useState(false);

    const handleSubmit = event => {
      event.preventDefault();
      // Save the subscription, then close the dialog.
      setOpen(false);
    };

    return (
      <Dialog open={open} onOpenChange={setOpen}>
        <DialogTrigger render={<Button />}>Sign up</DialogTrigger>
        <DialogContent className="sm:max-w-sm">
          <form onSubmit={handleSubmit} className="grid gap-6">
            <DialogHeader>
              <DialogTitle>Sign up for our newsletter</DialogTitle>
              <DialogDescription>Get product updates once a month.</DialogDescription>
            </DialogHeader>
            <FieldGroup>
              <Field>
                <FieldLabel htmlFor="newsletter-name">Name</FieldLabel>
                <Input id="newsletter-name" name="name" required />
              </Field>
              <Field>
                <FieldLabel htmlFor="newsletter-email">Email</FieldLabel>
                <Input id="newsletter-email" name="email" type="email" required />
              </Field>
            </FieldGroup>
            <DialogFooter>
              <DialogClose render={<Button variant="outline" />}>Cancel</DialogClose>
              <Button type="submit">Sign up</Button>
            </DialogFooter>
          </form>
        </DialogContent>
      </Dialog>
    );
  }
  ```
</Example>

## Close button

`DialogContent` shows a close button in the corner by default. Set `showCloseButton={false}` to hide
it, and `showCloseButton` on `DialogFooter` to add a Close button to the footer instead.

<Example>
  <Dialog>
    <DialogTrigger render={<Button variant="outline" />}>Share link</DialogTrigger>
    <DialogContent showCloseButton={false}>
      <DialogHeader>
        <DialogTitle>Share link</DialogTitle>
        <DialogDescription>Anyone who has this link will be able to view this page.</DialogDescription>
      </DialogHeader>
      <Input defaultValue="https://zen.umami.is/docs" aria-label="Link" readOnly />
      <DialogFooter showCloseButton />
    </DialogContent>
  </Dialog>


## Parts

- `Dialog` is the root. It holds the open state.
- `DialogTrigger` opens the dialog. Use `render={<Button />}` to style it.
- `DialogContent` is the popup, rendered in a portal over a backdrop. It sets its own width (`sm:max-w-md`); pass a `className` to change it.
- `DialogHeader`, `DialogTitle` and `DialogDescription` make up the header. Always include a `DialogTitle` so the dialog has an accessible name.
- `DialogFooter` lays out the actions.
- `DialogClose` closes the dialog. It also accepts `render`.

<PropertiesTable>
  <PropertiesTable.Row name="showCloseButton" type="boolean">Shows the close button in the top-right corner (default: true)</PropertiesTable.Row>
  <PropertiesTable.Row name="initialFocus" type="boolean | RefObject | function">Element to focus when the dialog opens</PropertiesTable.Row>
  <PropertiesTable.Row name="finalFocus" type="boolean | RefObject | function">Element to focus when the dialog closes</PropertiesTable.Row>
</PropertiesTable>

<PropertiesTable>
  <PropertiesTable.Row name="showCloseButton" type="boolean">Adds an outline Close button (default: false)</PropertiesTable.Row>
