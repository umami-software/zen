---
title: Data Card
---

import { DataCard, Example } from '../../../mdx-components';

A structured display component for presenting key-value pairs in a vertical list format. Useful for profile cards, detail panels, summary views, or any context where labeled data needs clear presentation.

<Example>
  <DataCard
    data={[
      { id: 'name', label: 'Name', value: 'Bob' },
      { id: 'title', label: 'Title', value: 'Vice President' },
      { id: 'age', label: 'Age', value: '42' },
    ]}
  />

  ```jsx
  <DataCard
    data={[
      { id: 'name', label: 'Name', value: 'Bob' },
      { id: 'title', label: 'Title', value: 'Vice President' },
      { id: 'age', label: 'Age', value: '42' },
    ]}
  />
  ```
</Example>

## Component props

<PropertiesTable>
  <ResponseField name="data" type="object[]">{"Array of { label, value } objects"}</ResponseField>
  <ResponseField name="labelWidth" type="string">Width of label column (default: "auto")</ResponseField>
</PropertiesTable>
