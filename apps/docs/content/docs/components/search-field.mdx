A specialized text input for search functionality, featuring a search icon and clear button. Provides familiar search UX patterns with keyboard support and accessible labeling. It is built on the shadcn `InputGroup`.

## With delay

`onSearch` is debounced by `delay`. It fires immediately when the user presses <kbd>Enter</kbd> or
clears the field.

<Example>
  <Box width="300px">
    <SearchDelayExample />
  </Box>

  ```jsx
  const [value, setValue] = useState('abc');

  <SearchField delay={1000} onSearch={setValue} />
  <TextField name="search" label="Search value" value={value} readOnly />
  ```
</Example>

## Component props

Native `input` props are passed to the input. `onChange` receives the native change event.

<PropertiesTable>
  <PropertiesTable.Row name="label" type="ReactNode">Label displayed above the field</PropertiesTable.Row>
  <PropertiesTable.Row name="placeholder" type="string">Placeholder text</PropertiesTable.Row>
  <PropertiesTable.Row name="value" type="string">Controlled value</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultValue" type="string">Initial value (uncontrolled)</PropertiesTable.Row>
  <PropertiesTable.Row name="delay" type="number">Debounce delay in ms before `onSearch` fires (default: 0)</PropertiesTable.Row>
  <PropertiesTable.Row name="onValueChange" type="(value: string) => void">Called with the new value on every change (and on clear)</PropertiesTable.Row>
  <PropertiesTable.Row name="onSearch" type="(value: string) => void">Called with the search term, debounced by `delay`</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Disables the field</PropertiesTable.Row>
</PropertiesTable>
