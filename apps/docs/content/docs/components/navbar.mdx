<ZenProvider>

A horizontal navigation bar for website headers. Built on an accessible navigation menu primitive, it supports dropdown menus, links, and nested navigation items with a shared animated dropdown, full keyboard navigation, and hover/focus interactions.

<Example>
  <Navbar>
    <NavbarItem label="Product">
      <Menu>
        <MenuItem>Features</MenuItem>
        <MenuItem>Pricing</MenuItem>
      </Menu>
    </NavbarItem>
    <NavbarItem label="Resources">
      <Menu>
        <MenuItem>Documentation</MenuItem>
        <MenuItem>API Reference</MenuItem>
        <MenuItem>Support</MenuItem>
      </Menu>
    </NavbarItem>
    <NavbarItem label="Company">
      <Menu>
        <MenuItem>About</MenuItem>

        <MenuItem>Careers</MenuItem>
      </Menu>

  </Navbar>

## Component props

### Navbar

<Example>
  <DataTable
    data={[
      { name: 'showArrow', value: 'boolean', description: 'Shows dropdown arrow on items (default: true)' },
    ]}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="value" label="Type" />
    <DataColumn id="description" label="Description" />
  </DataTable>
</Example>

### NavbarItem

<Example>
  <DataTable
    data={[
      { name: 'label', value: 'string', description: 'Item label. When set, the item becomes a trigger and its children render in the dropdown.' },
    ]}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="value" label="Type" />
    <DataColumn id="description" label="Description" />
  </DataTable>
</Example>

### NavbarLink

A semantic navigation link that renders an `<a>` element and participates in keyboard navigation. Use it for direct links instead of a plain anchor.

<Example>
  <DataTable
    data={[
      { name: 'href', value: 'string', description: 'The destination URL.' },
      { name: 'active', value: 'boolean', description: 'Marks the link as the current page (default: false).' },
    ]}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="value" label="Type" />
    <DataColumn id="description" label="Description" />
  </DataTable>
</Example>
