A horizontal navigation bar for website headers. Built on Base UI's `NavigationMenu`, it supports
dropdowns and links with a shared animated popup, full keyboard navigation, and hover/focus
interactions.

Give a `NavbarItem` a `label` to turn it into a dropdown trigger, and put `NavbarLink`s in its
children. A `NavbarItem` without a label renders its children directly.

<Example>
  <Navbar>
    <NavbarItem label="Product">
      <NavbarLink href="#">Features</NavbarLink>
      <NavbarLink href="#">Pricing</NavbarLink>
    </NavbarItem>
    <NavbarItem label="Resources">
      <NavbarLink href="#">Documentation</NavbarLink>
      <NavbarLink href="#">API Reference</NavbarLink>
      <NavbarLink href="#">Support</NavbarLink>
    </NavbarItem>
    <NavbarItem label="Company">
      <NavbarLink href="#">About</NavbarLink>
      <NavbarLink href="#">Blog</NavbarLink>
      <NavbarLink href="#">Careers</NavbarLink>
    </NavbarItem>
    <NavbarItem>
      <NavbarLink href="https://github.com/umami-software/umami">GitHub</NavbarLink>
    </NavbarItem>
  </Navbar>

## Router links

`NavbarLink` accepts Base UI's `render` prop, so it can render your router's link component.

```jsx
<NavbarItem>
  <NavbarLink render={<Link to="/pricing" />}>Pricing</NavbarLink>
</NavbarItem>
```

## Component props

### Navbar

<PropertiesTable>
  <PropertiesTable.Row name="showArrow" type="boolean">Shows the dropdown arrow on items that have a label (default: true)</PropertiesTable.Row>
</PropertiesTable>

### NavbarItem

<PropertiesTable>
  <PropertiesTable.Row name="label" type="ReactNode">Item label. When set, the item becomes a trigger and its children render in the dropdown.</PropertiesTable.Row>
</PropertiesTable>

### NavbarLink

A semantic navigation link that renders an `<a>` element and participates in keyboard navigation.
Inside a `NavbarItem` dropdown it renders as a menu row. It accepts Base UI `NavigationMenu.Link` props.

<PropertiesTable>
  <PropertiesTable.Row name="href" type="string">The destination URL.</PropertiesTable.Row>
  <PropertiesTable.Row name="active" type="boolean">Marks the link as the current page (default: false).</PropertiesTable.Row>
  <PropertiesTable.Row name="render" type="ReactElement">Renders a different element, such as a router link.</PropertiesTable.Row>
</PropertiesTable>
