## Custom separator

<Example>

    <BreadcrumbList>
      <BreadcrumbItem>
        <BreadcrumbLink href="#">Home</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator>
        <Lucide.Slash />
      </BreadcrumbSeparator>
      <BreadcrumbItem>
        <BreadcrumbLink href="#">Components</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator>
        <Lucide.Slash />
      </BreadcrumbSeparator>
      <BreadcrumbItem>
        <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
      </BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>

  ```jsx

    <BreadcrumbList>
      <BreadcrumbItem>
  ```

## Router links

`BreadcrumbLink` renders an `<a>`. Use the `render` prop to render your router's link component
instead.

```jsx
import { Link } from 'react-router';

<BreadcrumbItem>
  <BreadcrumbLink render={<Link to="/components" />}>Components</BreadcrumbLink>
</BreadcrumbItem>
```
