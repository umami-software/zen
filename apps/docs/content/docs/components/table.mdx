import { Badge, Box, Checkbox, Example, Table, TableBody, TableCaption, TableCell, TableFooter, TableHead, TableHeader, TableRow } from '../../../mdx-components';

A responsive table component. The parts map one-to-one to the native table elements and the table
scrolls horizontally when it is wider than its container. For sorting, selection and data-driven
columns, use [DataTable](/docs/components/data-table).

## Selected rows

`TableRow` highlights itself when it has `data-state="selected"`. Combine it with a `Checkbox` in
the first column to build row selection yourself.

<Example>
  <Box width="480px" maxWidth="100%">
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>
            <Checkbox aria-label="Select all" />
          </TableHead>
          <TableHead>Name</TableHead>
          <TableHead>Role</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow data-state="selected">
          <TableCell>
            <Checkbox aria-label="Select Sarah Chen" defaultChecked />
          </TableCell>
          <TableCell>Sarah Chen</TableCell>
          <TableCell>
            <Badge variant="secondary">Owner</Badge>
          </TableCell>
        </TableRow>
        <TableRow>
          <TableCell>
            <Checkbox aria-label="Select Marc Rivera" />
          </TableCell>
          <TableCell>Marc Rivera</TableCell>
          <TableCell>
            <Badge variant="outline">Member</Badge>
          </TableCell>
        </TableRow>
      </TableBody>
    </Table>
  </Box>

## Parts

<PropertiesTable>
  <PropertiesTable.Row name="Table" type="table">The table, wrapped in a horizontally scrolling container</PropertiesTable.Row>
  <PropertiesTable.Row name="TableHeader" type="thead">The header section</PropertiesTable.Row>
  <PropertiesTable.Row name="TableBody" type="tbody">The body section</PropertiesTable.Row>
  <PropertiesTable.Row name="TableFooter" type="tfoot">The footer section, on a muted background</PropertiesTable.Row>
  <PropertiesTable.Row name="TableRow" type="tr">A row. Highlights on hover and with `data-state="selected"`</PropertiesTable.Row>
  <PropertiesTable.Row name="TableHead" type="th">A header cell</PropertiesTable.Row>
  <PropertiesTable.Row name="TableCell" type="td">A body cell</PropertiesTable.Row>
  <PropertiesTable.Row name="TableCaption" type="caption">A caption below the table</PropertiesTable.Row>
</PropertiesTable>

All parts accept the props of the element they render, including `className`.
