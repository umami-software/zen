---
title: Confirmation Dialog
---

import { Button, ConfirmationDialog, ConfirmationDialogExample, DialogTrigger, Example, Modal, Text } from '../../../mdx-components';

A high-friction dialog for dangerous or irreversible actions. Requires users to type a confirmation phrase before proceeding, preventing accidental deletions or critical changes.

<Example>
  <ConfirmationDialogExample />

  ```jsx
    <DialogTrigger overlayType="alert-dialog">
    <Button variant="danger">Delete account</Button>
    <Modal>
      <ConfirmationDialog
        title="Delete account"
        value={'abc123'}
        confirmLabel="Delete"
        isDanger={true}
      >
        <Text>This cannot be undone. All your data will be permananently deleted.</Text>
      </ConfirmationDialog>
    </Modal>
  </DialogTrigger>
  ```
</Example>

## Component props

<PropertiesTable>
  <ResponseField name="value" type="string">Text the user must type to confirm (required)</ResponseField>
  <ResponseField name="confirmMessage" type="ReactNode">Message shown above the confirmation input</ResponseField>
  <ResponseField name="title" type="ReactNode">Dialog title</ResponseField>
  <ResponseField name="isDanger" type="boolean">Shows confirm button as danger variant</ResponseField>
  <ResponseField name="confirmLabel" type="ReactNode">Confirm button text</ResponseField>
  <ResponseField name="cancelLabel" type="ReactNode">Cancel button text</ResponseField>
  <ResponseField name="onConfirm" type="() => void">Called when confirmed</ResponseField>
  <ResponseField name="onCancel" type="() => void">Called when cancelled</ResponseField>
</PropertiesTable>
