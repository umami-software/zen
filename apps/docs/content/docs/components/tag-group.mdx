A tag group displays a collection of tags that can optionally be removed. Each `Tag` is a shadcn
`Badge`.

<Example>
  <TagGroup label="Categories">
    <Tag value="react">React</Tag>
    <Tag value="vue">Vue</Tag>
    <Tag value="angular">Angular</Tag>
  </TagGroup>

  ```jsx
  <TagGroup label="Categories">
    <Tag value="react">React</Tag>
    <Tag value="vue">Vue</Tag>
    <Tag value="angular">Angular</Tag>
  </TagGroup>
  ```
</Example>

## Removable

Add `onRemove` to make tags removable. An X button appears on each tag, and a focused tag can be
removed with <kbd>Backspace</kbd> or <kbd>Delete</kbd>. `onRemove` receives the tag's `value`.

<Example>
  <RemovableTagGroupExample />

  ```jsx
  const [tags, setTags] = useState(['JavaScript', 'TypeScript', 'Python']);

  <TagGroup label="Skills" onRemove={value => setTags(tags.filter(tag => tag !== value))}>
    {tags.map(tag => (
      <Tag key={tag} value={tag}>
        {tag}
      </Tag>
    ))}
  </TagGroup>
  ```
</Example>

## Variants

`variant` takes the shadcn `Badge` variants.

<Example>
  <Column gap="3">
    <TagGroup label="Secondary">
      <Tag>Secondary</Tag>
      <Tag>Tags</Tag>
    </TagGroup>
    <TagGroup label="Outline">
      <Tag variant="outline">Outline</Tag>
      <Tag variant="outline">Tags</Tag>
    </TagGroup>
    <TagGroup label="Default">
      <Tag variant="default">Default</Tag>
      <Tag variant="default">Tags</Tag>
    </TagGroup>
    <TagGroup label="Destructive">
      <Tag variant="destructive">Destructive</Tag>
      <Tag variant="destructive">Tags</Tag>
    </TagGroup>
  </Column>

  ```jsx
  <TagGroup label="Secondary">
    <Tag>Secondary</Tag>
    <Tag>Tags</Tag>
  </TagGroup>

  <TagGroup label="Outline">
    <Tag variant="outline">Outline</Tag>
    <Tag variant="outline">Tags</Tag>
  </TagGroup>

  <TagGroup label="Default">
    <Tag variant="default">Default</Tag>
    <Tag variant="default">Tags</Tag>
  </TagGroup>

  <TagGroup label="Destructive">
    <Tag variant="destructive">Destructive</Tag>
    <Tag variant="destructive">Tags</Tag>
  </TagGroup>
  ```
</Example>

## Component props

### TagGroup

<PropertiesTable>
  <PropertiesTable.Row name="label" type="ReactNode">Label displayed above the group</PropertiesTable.Row>
  <PropertiesTable.Row name="onRemove" type="(value: string) => void">Called with the removed tag's `value`. Enables remove buttons</PropertiesTable.Row>
</PropertiesTable>

### Tag

<PropertiesTable>
  <PropertiesTable.Row name="value" type="string">Identifies the tag in `onRemove`. Defaults to the text content when it is a string</PropertiesTable.Row>
  <PropertiesTable.Row name="variant" type="string">"secondary" | "default" | "outline" | "destructive" | "ghost" | "link" (default: "secondary")</PropertiesTable.Row>
  <PropertiesTable.Row name="disabled" type="boolean">Disables the tag so it cannot be removed</PropertiesTable.Row>
</PropertiesTable>
