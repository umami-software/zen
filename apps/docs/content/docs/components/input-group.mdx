import {
  Box,
  Column,
  Example,
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
  Kbd,
  Lucide,
  Spinner,
} from '../../../mdx-components';

Add icons, text, buttons and keyboard hints to inputs and textareas, without overlaying content or
padding the input by hand. Place `InputGroupAddon` after the control in the DOM and use `align` to
position it.

<Example>
  <Box width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput placeholder="Search..." />
      <InputGroupAddon>
        <Lucide.Search />
      </InputGroupAddon>
      <InputGroupAddon align="inline-end">
        <Kbd>⌘K</Kbd>
      </InputGroupAddon>
    </InputGroup>
  </Box>

  ```jsx
  <InputGroup>
    <InputGroupInput placeholder="Search..." />
    <InputGroupAddon>
      <Lucide.Search />
    </InputGroupAddon>
    <InputGroupAddon align="inline-end">
      <Kbd>⌘K</Kbd>
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

## Text

Use `InputGroupText` for prefixes and suffixes such as currency or units.

<Example>
  <Box width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput placeholder="0.00" inputMode="decimal" />
      <InputGroupAddon>
        <InputGroupText>$</InputGroupText>
      </InputGroupAddon>
      <InputGroupAddon align="inline-end">
        <InputGroupText>USD</InputGroupText>
      </InputGroupAddon>
    </InputGroup>
  </Box>

  ```jsx
  <InputGroup>
    <InputGroupInput placeholder="0.00" inputMode="decimal" />
    <InputGroupAddon>
      <InputGroupText>$</InputGroupText>
    </InputGroupAddon>
    <InputGroupAddon align="inline-end">
      <InputGroupText>USD</InputGroupText>
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

## Button

`InputGroupButton` is a compact `Button` sized for the group. It takes the `xs`, `sm`, `icon-xs` and
`icon-sm` sizes and any `Button` variant (default: `ghost`).

<Example>
  <Column gap width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput defaultValue="https://zen.umami.is" aria-label="URL" readOnly />
      <InputGroupAddon align="inline-end">
        <InputGroupButton size="icon-xs" aria-label="Copy URL">
          <Lucide.Copy />
        </InputGroupButton>
      </InputGroupAddon>
    </InputGroup>
    <InputGroup>
      <InputGroupInput placeholder="Enter your email" aria-label="Email" />
      <InputGroupAddon align="inline-end">
        <InputGroupButton variant="secondary">Subscribe</InputGroupButton>
      </InputGroupAddon>
    </InputGroup>
  </Column>

  ```jsx
  <InputGroup>
    <InputGroupInput defaultValue="https://zen.umami.is" aria-label="URL" readOnly />
    <InputGroupAddon align="inline-end">
      <InputGroupButton size="icon-xs" aria-label="Copy URL">
        <Lucide.Copy />
      </InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
  <InputGroup>
    <InputGroupInput placeholder="Enter your email" aria-label="Email" />
    <InputGroupAddon align="inline-end">
      <InputGroupButton variant="secondary">Subscribe</InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

## Textarea

Use the `block-start` and `block-end` alignments to place addons above or below a textarea.

<Example>
  <Box width="350px" maxWidth="100%">
    <InputGroup>
      <InputGroupTextarea placeholder="Ask, search or chat..." rows={3} />
      <InputGroupAddon align="block-end">
        <InputGroupText>52% used</InputGroupText>
        <InputGroupButton variant="default" size="icon-xs" className="ml-auto" aria-label="Send">
          <Lucide.ArrowUp />
        </InputGroupButton>
      </InputGroupAddon>
    </InputGroup>
  </Box>

  ```jsx
  <InputGroup>
    <InputGroupTextarea placeholder="Ask, search or chat..." rows={3} />
    <InputGroupAddon align="block-end">
      <InputGroupText>52% used</InputGroupText>
      <InputGroupButton variant="default" size="icon-xs" className="ml-auto" aria-label="Send">
        <Lucide.ArrowUp />
      </InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

## States

`InputGroup` follows the disabled and invalid state of its control.

<Example>
  <Column gap width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput defaultValue="Disabled" aria-label="Disabled" disabled />
      <InputGroupAddon align="inline-end">
        <Lucide.Lock />
      </InputGroupAddon>
    </InputGroup>
    <InputGroup>
      <InputGroupInput defaultValue="not-an-email" aria-label="Email" aria-invalid />
      <InputGroupAddon align="inline-end">
        <Lucide.CircleAlert />
      </InputGroupAddon>
    </InputGroup>
  </Column>

  ```jsx
  <InputGroup>
    <InputGroupInput defaultValue="Disabled" aria-label="Disabled" disabled />
    <InputGroupAddon align="inline-end">
      <Lucide.Lock />
    </InputGroupAddon>
  </InputGroup>
  <InputGroup>
    <InputGroupInput defaultValue="not-an-email" aria-label="Email" aria-invalid />
    <InputGroupAddon align="inline-end">
      <Lucide.CircleAlert />
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

For a custom control, add `data-slot="input-group-control"` so that clicking an addon focuses it and
the group picks up its focus and invalid styles.

## Component props

### InputGroupAddon

<PropertiesTable>
  <PropertiesTable.Row name="align" type="string">"inline-start" | "inline-end" | "block-start" | "block-end" (default: "inline-start")</PropertiesTable.Row>
</PropertiesTable>

### InputGroupButton

<PropertiesTable>
  <PropertiesTable.Row name="size" type="string">"xs" | "sm" | "icon-xs" | "icon-sm" (default: "xs")</PropertiesTable.Row>
  <PropertiesTable.Row name="variant" type="ButtonVariant">Any `Button` variant (default: "ghost")</PropertiesTable.Row>
</PropertiesTable>

`InputGroupInput` and `InputGroupTextarea` accept the native `input` and `textarea` props.
