import { Box, Column, Example, InputGroup, InputGroupAddon, InputGroupButton, InputGroupInput, InputGroupText, InputGroupTextarea, Lucide, ZenProvider } from '../../../mdx-components';

<ZenProvider>

Input groups compose controls with icons, text, and actions without overlaying content or adding
manual input padding. Keep addons after the control in the DOM and use `align` to place them
visually.

## Leading icon

<Example>
  <Box width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput placeholder="Search..." />
      <InputGroupAddon align="inline-start">
        <Lucide.Search />
      </InputGroupAddon>
    </InputGroup>
  </Box>

  ```jsx
  <InputGroup>
    <InputGroupInput placeholder="Search..." />
    <InputGroupAddon align="inline-start">
      <Search />
    </InputGroupAddon>
  </InputGroup>
  ```
</Example>

## States and RTL

<Example>
  <Column gap width="300px" maxWidth="100%">
    <InputGroup>
      <InputGroupInput value="Read only" readOnly />
      <InputGroupAddon align="inline-end">
        <Lucide.Lock />
      </InputGroupAddon>
    </InputGroup>
    <InputGroup>
      <InputGroupInput value="Disabled" disabled />
      <InputGroupAddon align="inline-end">
        <Lucide.Lock />
      </InputGroupAddon>
    </InputGroup>
    <div dir="rtl">
      <InputGroup>
        <InputGroupInput placeholder="بحث..." />
        <InputGroupAddon align="inline-start">
          <Lucide.Search />
        </InputGroupAddon>
      </InputGroup>
    </div>
  </Column>
</Example>

For custom controls, add `data-slot="input-group-control"` so addons can focus the control and the
group can apply consistent state styling.

</ZenProvider>
