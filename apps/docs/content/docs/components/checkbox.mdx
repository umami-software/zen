import { Box, Checkbox, Example, Field, FieldContent, FieldDescription, FieldGroup, FieldLabel } from '../../../mdx-components';

A control that allows the user to toggle between checked and not checked. `Checkbox` renders only
the box, so pair it with a `FieldLabel` (or `Label`) using `id` and `htmlFor`.

<Example>
  <Field orientation="horizontal">
    <Checkbox id="terms" />
    <FieldLabel htmlFor="terms">Accept terms and conditions</FieldLabel>
  </Field>

  ```jsx
  <Field orientation="horizontal">
    <Checkbox id="terms" />
    <FieldLabel htmlFor="terms">Accept terms and conditions</FieldLabel>
  </Field>
  ```
</Example>

## Description

Wrap the label and a description in `FieldContent`.

<Example>
  <Box width="350px" maxWidth="100%">
    <Field orientation="horizontal">
      <Checkbox id="notifications" defaultChecked />
      <FieldContent>
        <FieldLabel htmlFor="notifications">Enable notifications</FieldLabel>
        <FieldDescription>You can enable or disable notifications at any time.</FieldDescription>
      </FieldContent>
    </Field>
  </Box>

  ```jsx
  <Field orientation="horizontal">
    <Checkbox id="notifications" defaultChecked />
    <FieldContent>
      <FieldLabel htmlFor="notifications">Enable notifications</FieldLabel>
      <FieldDescription>You can enable or disable notifications at any time.</FieldDescription>
    </FieldContent>
  </Field>
  ```
</Example>

## Controlled

```jsx
const [checked, setChecked] = useState(false);

<Checkbox id="subscribe" checked={checked} onCheckedChange={setChecked} />
```

To manage a set of checkboxes as one value, use `CheckboxGroup`.
