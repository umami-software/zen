A carousel displays a set of slides that users can scroll through.

## Component props

### Carousel

<PropertiesTable>
  <ResponseField name="orientation" type="string">"horizontal" | "vertical" (default: "horizontal")</ResponseField>
  <ResponseField name="loop" type="boolean">Loops back to the first slide</ResponseField>
  <ResponseField name="showArrows" type="boolean">Shows previous/next arrows (default: true)</ResponseField>
  <ResponseField name="showDots" type="boolean">Shows dot indicators</ResponseField>
  <ResponseField name="opts" type="EmblaOptions">Additional Embla carousel options</ResponseField>
  <ResponseField name="onIndexChange" type="(index: number) => void">Called when the selected slide changes</ResponseField>
</PropertiesTable>

### CarouselItem

Accepts standard HTML div props. Each item renders as a slide.
