A carousel with motion and swipe built using [Embla](https://www.embla-carousel.com). Put the
slides in `CarouselContent` and add `CarouselPrevious` and `CarouselNext` for the arrow buttons.
The arrow keys also move between slides.

## Sizes

Set a `basis` class on `CarouselItem` to show several slides at once.

<Example>
  <CarouselSizesExample />

  ```jsx
  <Carousel className="w-full max-w-sm">
    <CarouselContent>
      {Array.from({ length: 5 }).map((_, index) => (
        <CarouselItem key={index} className="basis-1/2 lg:basis-1/3">
          <Slide index={index} />
        </CarouselItem>
      ))}
    </CarouselContent>
    <CarouselPrevious />
    <CarouselNext />
  </Carousel>
  ```
</Example>

## Options and loop

`opts` is passed to Embla. For example, `opts={{ loop: true }}` wraps around from the last slide to
the first, and `opts={{ align: 'start' }}` aligns slides to the start of the viewport.

## API

Use `setApi` to get the Embla API, for example to show the current slide.

<Example>
  <CarouselApiExample />

  ```jsx
  function CarouselApiExample() {
    const [api, setApi] = useState();
    const [current, setCurrent] = useState(0);
    const [count, setCount] = useState(0);

    useEffect(() => {
      if (!api) return;

      setCount(api.scrollSnapList().length);
      setCurrent(api.selectedScrollSnap() + 1);

      const onSelect = () => setCurrent(api.selectedScrollSnap() + 1);
      api.on('select', onSelect);

      return () => {
        api.off('select', onSelect);
      };
    }, [api]);

    return (
      <Column alignItems="center" gap="2" className="w-full max-w-xs">
        <Carousel setApi={setApi} className="w-full">
          <CarouselContent>
            {Array.from({ length: 5 }).map((_, index) => (
              <CarouselItem key={index}>
                <Slide index={index} />
              </CarouselItem>
            ))}
          </CarouselContent>
          <CarouselPrevious />
          <CarouselNext />
        </Carousel>
        <Text size="sm" color="muted-foreground">
          Slide {current} of {count}
        </Text>
      </Column>
    );
  }
  ```
</Example>

## Parts

- `Carousel` is the root. It owns the Embla instance and keyboard handling.
- `CarouselContent` is the scrolling track.
- `CarouselItem` is one slide. Size it with a `basis-*` class.
- `CarouselPrevious` and `CarouselNext` are outline icon buttons placed outside the track. They accept `Button` props.
