A declarative table component for displaying structured data with minimal configuration. Define columns and pass data to quickly render formatted tables. Ideal for admin panels, lists, and data-heavy interfaces. It is built on [TanStack Table](https://tanstack.com/table) and the shadcn `Table` parts, and supports sorting, filtering, pagination and row selection.

## Row selection

Set `selectionMode` to add a checkbox column. Rows are keyed by their `id` property (or their index
without one); pass `getRowId` to use something else. With a `filter`, the header checkbox selects
only the matching rows. Use `selectedRows` and
`onSelectedRowsChange` to control the selection, or `defaultSelectedRows` for an initial value.

<Example>
  <DataTable
    selectionMode="multiple"
    defaultSelectedRows={['2']}
    data={[
      { id: 1, name: 'Bob', title: 'CEO', email: 'bob@aol.com' },
      { id: 2, name: 'Fred', title: 'VP Marketing', email: 'fred@aol.com' },
      { id: 3, name: 'Ted', title: 'Engineer', email: 'ted@aol.com' },
    ]}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
  </DataTable>

  ```jsx
  <DataTable
    data={data}
    selectionMode="multiple"
    defaultSelectedRows={['2']}
    onSelectedRowsChange={rows => console.log(rows)}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
  </DataTable>
  ```
</Example>

## Sorting

Set `sortable` on a column to sort by clicking its header. Clicking cycles through ascending,
descending and unsorted; shift-click to sort by several columns. Use `defaultSorting` for an initial
order, or `sorting` and `onSortingChange` to control it.

A column sorts by `row[id]` unless you pass `value`, which also feeds filtering. Here `Joined` shows
a formatted date but sorts by the `Date`.

<Example>
  <DataTableSortingExample />

  ```jsx
  <DataTable data={data} defaultSorting={[{ id: 'name', desc: false }]}>
    <DataColumn id="name" label="Name" sortable />
    <DataColumn id="title" label="Title" sortable />
    <DataColumn id="joined" label="Joined" sortable value={row => new Date(row.joined)}>
      {row => formatDate(row.joined)}
    </DataColumn>
  </DataTable>
  ```
</Example>

## Filtering

Pass a search term to `filter` to show only rows where a column contains it, ignoring case. Text and
number columns are searched; set `filterable={false}` on a column to leave it out. `emptyState`
replaces the default "No results." message.

<Example>
  <DataTableFilterExample />

  ```jsx
  const [search, setSearch] = useState('');

  <SearchField placeholder="Search members" value={search} onValueChange={setSearch} />
  <DataTable data={data} filter={search} emptyState="No members match your search.">
    <DataColumn id="name" label="Name" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
  </DataTable>
  ```
</Example>

## Pagination

Set `pageSize` to split the rows into pages, with Previous and Next controls below the table. Use
`defaultPageIndex`, or `pageIndex` and `onPageIndexChange`, for the current page (starting at 0).
Sorting and filtering apply across all pages, and changing them returns to the first page.

<Example>
  <DataTablePaginationExample />

  ```jsx
  <DataTable data={data} pageSize={3}>
    <DataColumn id="name" label="Name" sortable />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
  </DataTable>
  ```
</Example>

## Loading

Set `loading` while the data is being fetched. The headers stay in place and the body shows
placeholder rows that follow the column widths and alignment, so the layout doesn't shift when the
data arrives. It shows `pageSize` rows, or 5 without paging; `loadingRows` sets the number. Pagination
is hidden while loading, and card mode shows placeholder cards.

<Example>
  <DataTable data={[]} loading loadingRows={3} selectionMode="multiple">
    <DataColumn id="id" label="ID" width="50px" />
    <DataColumn id="name" label="Name" width="2fr" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" align="end" />
  </DataTable>

  ```jsx
  const { data, isLoading } = useQuery(...);

  <DataTable data={data} loading={isLoading} loadingRows={3}>
    <DataColumn id="id" label="ID" width="50px" />
    <DataColumn id="name" label="Name" width="2fr" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" align="end" />
  </DataTable>
  ```
</Example>

## As cards

Set `displayMode="cards"` to show each row as a card, for example on small screens. Sorting,
`filter`, pagination and selection still apply; with `selectionMode`, each card gets a checkbox.
There are no headers in this mode, so set the order with `sorting` or `defaultSorting`.

### Custom cards

Pass `renderCard` to draw each card yourself. It gets the row and a context with the row's `id` and
`index`, `isSelected`, `toggleSelected`, and `cells`: each visible column's rendered cell by column id,
so custom cells defined on `DataColumn` can be reused. Sorting, filtering, pagination and selection
still apply. No checkbox is added, so place your own with `isSelected` and `toggleSelected`.

While `loading`, the default placeholder card doesn't match a custom card, so pass
`renderCardSkeleton` to draw your own. Press Reload to see it.

<Example>
  <DataTableCustomCardExample />

  ```jsx
  <DataTable
    data={data}
    displayMode="cards"
    cardMinWidth="240px"
    selectionMode="multiple"
    loading={isLoading}
    renderCard={(member, { isSelected, toggleSelected, cells }) => (
      <Card size="sm">
        <CardContent>
          <Row gap="3" alignItems="center">
            <Avatar>
              <AvatarFallback>{initials(member.name)}</AvatarFallback>
            </Avatar>
            <Column flexGrow="1">
              <span className="font-medium">{member.name}</span>
              <span className="text-muted-foreground">{member.title}</span>
            </Column>
            <Checkbox checked={isSelected} onCheckedChange={checked => toggleSelected(checked)} />
          </Row>
          <div className="mt-3">{cells.email}</div>
        </CardContent>
      </Card>
    )}
    renderCardSkeleton={() => (
      <Card size="sm">
        <CardContent>
          <Row gap="3" alignItems="center">
            <Skeleton className="size-8 rounded-full" />
            <Column gap="1" flexGrow="1">
              <Skeleton className="h-4 w-24" />
              <Skeleton className="h-4 w-16" />
            </Column>
          </Row>
          <Skeleton className="mt-3 h-4 w-3/4" />
        </CardContent>
      </Card>
    )}
  >
    <DataColumn id="name" label="Name" />
    <DataColumn id="email" label="Email">
      {row => <a href={`mailto:${row.email}`}>{row.email}</a>}
    </DataColumn>
  </DataTable>
  ```
</Example>

## Component props

### DataTable

Other shadcn `Table` props are passed through.

<PropertiesTable>
  <PropertiesTable.Row name="data" type="TData[]">Array of data objects to display</PropertiesTable.Row>
  <PropertiesTable.Row name="getRowId" type="(row, index) => string">Returns a row's unique id (default: the row's `id`, or its index)</PropertiesTable.Row>
  <PropertiesTable.Row name="displayMode" type="string">"table" | "cards" (default: "table")</PropertiesTable.Row>
  <PropertiesTable.Row name="cardMinWidth" type="string">In card mode, the minimum width of a card; cards fill as many columns as fit (default: one column)</PropertiesTable.Row>
  <PropertiesTable.Row name="renderCard" type="(row, context) => ReactNode">In card mode, renders each card in place of the default; `context` has `id`, `index`, `isSelected`, `toggleSelected` and `cells`</PropertiesTable.Row>
  <PropertiesTable.Row name="renderCardSkeleton" type="(index: number) => ReactNode">In card mode, renders a placeholder card while `loading`</PropertiesTable.Row>
  <PropertiesTable.Row name="selectionMode" type="string">"none" | "single" | "multiple" (default: "none")</PropertiesTable.Row>
  <PropertiesTable.Row name="selectedRows" type="string[]">Selected row ids (controlled)</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultSelectedRows" type="string[]">Initially selected row ids (uncontrolled)</PropertiesTable.Row>
  <PropertiesTable.Row name="onSelectedRowsChange" type="(selectedRows: string[]) => void">Called with the new list of selected row ids</PropertiesTable.Row>
  <PropertiesTable.Row name="sorting" type="{ id: string, desc: boolean }[]">Sorted columns, in priority order (controlled)</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultSorting" type="{ id: string, desc: boolean }[]">Initially sorted columns (uncontrolled)</PropertiesTable.Row>
  <PropertiesTable.Row name="onSortingChange" type="(sorting) => void">Called when the user changes the sorting</PropertiesTable.Row>
  <PropertiesTable.Row name="filter" type="string">Shows only rows where a filterable column contains this text (case-insensitive)</PropertiesTable.Row>
  <PropertiesTable.Row name="pageSize" type="number">Splits rows into pages of this size and shows Previous and Next controls</PropertiesTable.Row>
  <PropertiesTable.Row name="pageIndex" type="number">Current page, starting at 0 (controlled)</PropertiesTable.Row>
  <PropertiesTable.Row name="defaultPageIndex" type="number">Initial page, starting at 0 (uncontrolled)</PropertiesTable.Row>
  <PropertiesTable.Row name="onPageIndexChange" type="(pageIndex: number) => void">Called when the page changes</PropertiesTable.Row>
  <PropertiesTable.Row name="emptyState" type="ReactNode">Shown when there are no rows (default: "No results.")</PropertiesTable.Row>
  <PropertiesTable.Row name="loading" type="boolean">Shows placeholder rows in place of the data, keeping the headers and column layout</PropertiesTable.Row>
  <PropertiesTable.Row name="loadingRows" type="number">Number of placeholder rows while `loading` (default: `pageSize`, or 5)</PropertiesTable.Row>
</PropertiesTable>

### DataColumn

<PropertiesTable>
  <PropertiesTable.Row name="id" type="string">Column key matching a data property (required)</PropertiesTable.Row>
  <PropertiesTable.Row name="label" type="ReactNode">Column header</PropertiesTable.Row>
  <PropertiesTable.Row name="width" type="string">Column width (e.g., "100px", "2fr"). Default: "1fr"</PropertiesTable.Row>
  <PropertiesTable.Row name="align" type="string">"start" | "center" | "end"</PropertiesTable.Row>
  <PropertiesTable.Row name="hidden" type="boolean">Hides the column</PropertiesTable.Row>
  <PropertiesTable.Row name="as" type="string">Element to wrap the cell value in</PropertiesTable.Row>
  <PropertiesTable.Row name="value" type="(row) => unknown">The column's value for a row, used for sorting, filtering and the default cell (default: `row[id]`)</PropertiesTable.Row>
  <PropertiesTable.Row name="sortable" type="boolean">Lets users sort by this column by clicking its header</PropertiesTable.Row>
  <PropertiesTable.Row name="filterable" type="boolean">Includes the column when matching `filter` (default: true for text and number values)</PropertiesTable.Row>
  <PropertiesTable.Row name="children" type="ReactNode | (row, index) => ReactNode">Static cell content, or a function that renders the cell from its row</PropertiesTable.Row>
</PropertiesTable>

For typed rows, pass the row type to `DataTable` and `DataColumn` in TypeScript, e.g.
`<DataColumn<User> id="email">{row => row.email}</DataColumn>`.
