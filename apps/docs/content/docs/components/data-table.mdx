title: Data Table

import { Button, DataColumn, DataTable, Example, Menu, MenuItem, MenuTrigger } from '../../../mdx-components';

A declarative table component for displaying structured data with minimal configuration. Define columns and pass data to quickly render sortable, formatted tables. Ideal for admin panels, lists, and data-heavy interfaces.

<Example>
  <DataTable
    data={[
      { id: 1, name: 'Bob', title: 'CEO', email: <a href="#">bob@aol.com</a> },
      { id: 2, name: 'Fred', title: 'VP Marketing', email: <a href="#">fred@aol.com</a> },
      { id: 3, name: 'Ted', title: 'Engineer', email: <a href="#">ted@aol.com</a> },
    ]}
  >
    <DataColumn id="id" label="ID" />
    <DataColumn id="name" label="Name" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
    <DataColumn id="actions" label="" align="end">
      <MenuTrigger>
        <Button variant="outline" size="xs">
          {`⋯`}
        </Button>
        <Menu>
          <MenuItem id="email">Send email</MenuItem>
          <MenuItem id="phone">Call phone</MenuItem>
        </Menu>
      </MenuTrigger>
    </DataColumn>
  </DataTable>

  ```jsx
  <DataTable data={data}>
    <DataColumn id="id" label="ID" />
    <DataColumn id="name" label="Name" />
    <DataColumn id="title" label="Title" />
    <DataColumn id="email" label="Email" />
  </DataTable>
  ```
</Example>

## As cards

  ```jsx

  </DataTable>
  ```
</Example>

## Component props

### DataTable

<PropertiesTable>
  <ResponseField name="data" type="object[]">Array of data objects to display</ResponseField>
  <ResponseField name="displayMode" type="DisplayMode">"table" | "cards"</ResponseField>
</PropertiesTable>

### DataColumn

<PropertiesTable>
  <ResponseField name="id" type="string">Column key matching data property (required)</ResponseField>
  <ResponseField name="label" type="string">Column header text</ResponseField>
  <ResponseField name="width" type="string">Column width (e.g., "100px", "2fr")</ResponseField>
  <ResponseField name="align" type="Alignment">"start" | "center" | "end"</ResponseField>
</PropertiesTable>
