**Zen** is [Umami’s](https://umami.is) design system for building consistent React interfaces.

It includes components, layout primitives, and a theme used across Umami products.
This documentation covers installation, component APIs, and the theme.

Source code is available on [GitHub](https://github.com/umami-software/react-zen).

## Implementation

Zen is built on [shadcn/ui](https://ui.shadcn.com/), with [Base UI](https://base-ui.com/)
primitives for interactive behavior and [Tailwind CSS](https://tailwindcss.com/) v4 for styling.

- **shadcn components** (Button, Dialog, DropdownMenu, Select, Tabs, Tooltip and the rest) are the
  unmodified shadcn components, exported with shadcn's names and parts. Their
  [shadcn documentation](https://ui.shadcn.com/docs/components) applies as written.
- **Zen components** add what shadcn doesn't have: layout and typography primitives with style props
  (Box, Row, Column, Grid, Text, Heading), richer fields (TextField, SearchField, NumberField,
  DatePicker), forms built on react-hook-form, DataTable, toasts, theming and more.
- **The theme** is the shadcn token set (`--background`, `--primary`, `--muted`, …) with
  palettes, `.dark` mode and a few additional tokens of Zen's own. See
  [colors](/docs/design/colors) for the full list.

## What is included

- A theme with [colors](/docs/design/colors), [palettes and dark mode](/docs/design/themes), and
  [customization](/docs/design/customization) through shadcn CSS variables
- Layout and typography primitives
- Form controls and interactive components
- Reusable interface patterns and composed components

## Basic usage

After [installing the package](/docs/install), wrap the application with `ZenProvider` and import
the components you need.

```jsx
import { Button, ZenProvider } from '@umami/react-zen';

export function App() {
  return (
    <ZenProvider>
      <Button>Save</Button>
    </ZenProvider>
  );
}
```
