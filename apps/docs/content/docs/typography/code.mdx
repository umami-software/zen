An inline code element for displaying code snippets, file names, commands, or technical terms within text. Styled with a monospace font and subtle background for visual distinction.

<Example>
  <Text>
    You can make changes to your <Code>package.json</Code> file.
  </Text>

  ```jsx
  <Text>
    You can make changes to your <Code>package.json</Code> file.
  </Text>
  ```
</Example>

## Component props

Code renders a `code` element with a monospace font and a `muted` background. It extends [Text](/docs/typography/text) and accepts all Text props except `as`.

  <PropertiesTable.Row name="children" type="ReactNode">Code content</PropertiesTable.Row>

</PropertiesTable>
