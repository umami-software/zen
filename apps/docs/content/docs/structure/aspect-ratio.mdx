import { AspectRatio, Box, Column, Example, Flexbox, Grid, Text } from '../../../mdx-components';

Displays content within a desired ratio. `AspectRatio` takes the full width of its container and
sets its height from `ratio`, the width divided by the height.

<Example>
  <Box width="400px" maxWidth="100%">
    <AspectRatio ratio={16 / 9} className="rounded-lg bg-muted">
      <img src="/images/sample.jpg" alt="Sample" className="size-full rounded-lg object-cover" />
    </AspectRatio>
  </Box>

  ```jsx
  <AspectRatio ratio={16 / 9} className="rounded-lg bg-muted">
    <img src="/images/sample.jpg" alt="Sample" className="size-full rounded-lg object-cover" />
  </AspectRatio>
  ```
</Example>

## Common ratios

`ratio` is required. Pass any width-to-height ratio.

<Example>
  <Grid gap="3" columns="3" width="600px" maxWidth="100%">
    <Column gap="2">
      <Text size="sm" weight="medium">1 / 1</Text>
      <AspectRatio ratio={1}>
        <Flexbox alignItems="center" justifyContent="center" height="100%" backgroundColor="muted" borderRadius>
          <Text size="sm" color="muted-foreground">Square</Text>
        </Flexbox>
      </AspectRatio>
    </Column>
    <Column gap="2">
      <Text size="sm" weight="medium">4 / 3</Text>
      <AspectRatio ratio={4 / 3}>
        <Flexbox alignItems="center" justifyContent="center" height="100%" backgroundColor="muted" borderRadius>
          <Text size="sm" color="muted-foreground">Standard</Text>
        </Flexbox>
      </AspectRatio>
    </Column>
    <Column gap="2">

      <AspectRatio ratio={16 / 9}>
        <Flexbox alignItems="center" justifyContent="center" height="100%" backgroundColor="muted" borderRadius>
          <Text size="sm" color="muted-foreground">Widescreen</Text>
        </Flexbox>

    </Column>
  </Grid>

## Component props

<PropertiesTable>
  <PropertiesTable.Row name="ratio" type="number">Width divided by height, e.g. `16 / 9` (required)</PropertiesTable.Row>
</PropertiesTable>

`AspectRatio` renders a `div` and accepts its props, including `className`.
