import { Box, Column, Example, Row, ScrollArea, ScrollBar, Separator, Text } from '../../../mdx-components';

Augments native scroll functionality for custom, cross-browser styling. Give the `ScrollArea` a
fixed height (or width) and its content scrolls inside it with a styled scrollbar.

<Example>
  <Box width="192px" height="288px" border borderRadius="md">
    <ScrollArea className="h-full">
      <Box padding="4">
        <Text as="h4" size="sm" weight="medium">Tags</Text>
        {Array.from({ length: 50 }, (_, i) => `v1.2.0-beta.${50 - i}`).map(tag => (
          <Column key={tag} gap="2" paddingTop="2">
            <Separator />
            <Text size="sm">{tag}</Text>
          </Column>
        ))}
      </Box>
    </ScrollArea>
  </Box>


</Example>

## Horizontal

`ScrollArea` renders a vertical scrollbar. Add a `ScrollBar` with `orientation="horizontal"` to
scroll sideways.

<Example>
  <Box width="384px" maxWidth="100%" border borderRadius="md">
    <ScrollArea>
      <Row gap="4" padding="4" width="max-content">
        {['Ornella Binni', 'Tom Byrom', 'Vladimir Malyavko', 'Jane Doe', 'Marc Rivera'].map(artist => (
          <Box key={artist} width="160px">
            <Box height="200px" backgroundColor="muted" borderRadius="md" />
            <Text as="p" size="xs" color="muted-foreground">
              Photo by {artist}
            </Text>
          </Box>
        ))}
      </Row>
      <ScrollBar orientation="horizontal" />
    </ScrollArea>
  </Box>

  ```jsx
  <Box width="384px" maxWidth="100%" border borderRadius="md">
    <ScrollArea>
      <Row gap="4" padding="4" width="max-content">
        {['Ornella Binni', 'Tom Byrom', 'Vladimir Malyavko', 'Jane Doe', 'Marc Rivera'].map(artist => (
          <Box key={artist} width="160px">
            <Box height="200px" backgroundColor="muted" borderRadius="md" />

              Photo by {artist}
            </Text>
          </Box>
        ))}
      </Row>
      <ScrollBar orientation="horizontal" />

  </Box>
  ```
</Example>

## Parts

### ScrollArea

The Base UI `ScrollArea.Root`, with the viewport, a vertical `ScrollBar` and the corner built in.
Set its size with `className` or a sized parent.
