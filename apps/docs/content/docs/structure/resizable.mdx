title: Resizable

import { Box, Example, Flexbox, ResizableHandle, ResizablePanel, ResizablePanelGroup } from '../../../mdx-components';

Resizable panels allow users to adjust the size of adjacent sections by dragging a handle.

<Example>
  <Box width="400px" height="200px" border borderRadius="lg" overflow="hidden">
    <ResizablePanelGroup direction="horizontal">
      <ResizablePanel defaultSize={50}>
        <Flexbox alignItems="center" justifyContent="center" height="100%">One</Flexbox>
      </ResizablePanel>
      <ResizableHandle withHandle />
      <ResizablePanel defaultSize={50}>
        <Flexbox alignItems="center" justifyContent="center" height="100%">Two</Flexbox>
      </ResizablePanel>
    </ResizablePanelGroup>
  </Box>

  ```jsx
  <ResizablePanelGroup direction="horizontal">
    <ResizablePanel defaultSize={50}>One</ResizablePanel>
    <ResizableHandle withHandle />
    <ResizablePanel defaultSize={50}>Two</ResizablePanel>
  </ResizablePanelGroup>
  ```
</Example>

## Component props

### ResizablePanelGroup

<PropertiesTable>
  <ResponseField name="direction" type="string">"horizontal" | "vertical" (default: "horizontal")</ResponseField>
</PropertiesTable>

### ResizablePanel

<PropertiesTable>
  <ResponseField name="defaultSize" type="number">Initial size as a percentage</ResponseField>
  <ResponseField name="minSize" type="number">Minimum size as a percentage</ResponseField>
  <ResponseField name="maxSize" type="number">Maximum size as a percentage</ResponseField>
  <ResponseField name="collapsible" type="boolean">Allows the panel to collapse below its minimum size</ResponseField>
</PropertiesTable>

### ResizableHandle

<PropertiesTable>
  <ResponseField name="withHandle" type="boolean">Shows a visible grip on the handle</ResponseField>
</PropertiesTable>
