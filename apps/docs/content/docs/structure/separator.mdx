---
title: Separator
description: "Visually or semantically separates content."
---

import { Box, Column, Example, Row, Separator, Text } from '../../../mdx-components';

Visually or semantically separates content. A horizontal separator fills the width of its
container; a vertical one stretches to the height of its row.

<Example>
  <Box width="320px" maxWidth="100%">
    <Column gap="1">
      <Text size="sm" weight="medium">React Zen</Text>
      <Text size="sm" color="muted">An open-source UI component library.</Text>
    </Column>
    <Box marginY="4">
      <Separator />
    </Box>
    <Row gap="4" alignItems="center" height="20px">
      <Text size="sm">Blog</Text>
      <Separator orientation="vertical" />
      <Text size="sm">Docs</Text>
      <Separator orientation="vertical" />
      <Text size="sm">Source</Text>
    </Row>
  </Box>

  ```jsx
  <Column gap="1">
    <Text size="sm" weight="medium">React Zen</Text>
    <Text size="sm" color="muted">An open-source UI component library.</Text>
  </Column>
  <Box marginY="4">
    <Separator />
  </Box>
  <Row gap="4" alignItems="center" height="20px">
    <Text size="sm">Blog</Text>
    <Separator orientation="vertical" />
    <Text size="sm">Docs</Text>
    <Separator orientation="vertical" />
    <Text size="sm">Source</Text>
  </Row>
  ```
</Example>

## Vertical

A vertical separator needs a parent with a height, such as a row of fixed height.

<Example>
  <Row gap="3" alignItems="center" height="20px">
    <Text size="sm">Settings</Text>
    <Separator orientation="vertical" />
    <Text size="sm">Account</Text>
  </Row>

  ```jsx
  <Row gap="3" alignItems="center" height="20px">
    <Text size="sm">Settings</Text>
    <Separator orientation="vertical" />
    <Text size="sm">Account</Text>
  </Row>
  ```
</Example>

## Component props

<PropertiesTable>
  <PropertiesTable.Row name="orientation" type="string">"horizontal" | "vertical" (default: "horizontal")</PropertiesTable.Row>
</PropertiesTable>

`Separator` renders the Base UI separator with `role="separator"` and accepts `className`.
