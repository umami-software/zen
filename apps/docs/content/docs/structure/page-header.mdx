Provides a consistent title and action area for a page.

<Example>
  <PageHeader>
    <PageHeaderTitle
      title="Users"
      description="Manage team members and permissions."
    />
    <PageHeaderActions>
      <Button variant="outline">Export</Button>
      <Button>Add user</Button>
    </PageHeaderActions>
  </PageHeader>

```jsx
import {
  Button,
  PageHeader,
  PageHeaderActions,
  PageHeaderTitle,
} from '@umami/react-zen';

<PageHeader>
  <PageHeaderTitle
    title="Users"
    description="Manage team members and permissions."
  />
  <PageHeaderActions>
    <Button variant="outline">Export</Button>
    <Button>Add user</Button>
  </PageHeaderActions>
</PageHeader>
```
</Example>

## Components

### PageHeader

The outer layout. It accepts `Row` props.

### PageHeaderTitle

Displays the breadcrumb, title, description (in `muted-foreground`), and optional children. It accepts `Column` props.

| Prop | Type | Description |
|------|------|-------------|
| `title` | `ReactNode` | Page title |
| `description` | `ReactNode` | Supporting text |
| `breadcrumb` | `ReactNode` | Content displayed above the title |

### PageHeaderActions

Groups page-level actions. It accepts `Row` props.

## Examples

### With breadcrumb

Pass any content as `breadcrumb`, such as the shadcn `Breadcrumb` parts.

<Example>
  <PageHeader>
    <PageHeaderTitle
      breadcrumb={
        <Breadcrumb>
          <BreadcrumbList>
            <BreadcrumbItem>
              <BreadcrumbLink href="#">Settings</BreadcrumbLink>
            </BreadcrumbItem>
            <BreadcrumbSeparator />
            <BreadcrumbItem>
              <BreadcrumbPage>Team</BreadcrumbPage>
            </BreadcrumbItem>
          </BreadcrumbList>
        </Breadcrumb>
      }
      title="Team members"
      description="Invite and manage team members."
    />
    <PageHeaderActions>
      <Button>Invite member</Button>
    </PageHeaderActions>
  </PageHeader>
