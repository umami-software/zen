A versatile layout primitive that serves as the foundation for building UI. Box provides comprehensive styling props for spacing, colors, borders, positioning, and more. Use it to wrap and position other components, create cards, or build custom layouts.

<Example>
  <Box>I am a box.</Box>

  ```jsx
  <Box>I am a box.</Box>
  ```
</Example>

## With properties

<Example>
  <Box padding="5" shadow="lg" borderRadius="lg" border>
    I am a box.
  </Box>

  ```jsx
  <Box padding="5" shadow="lg" borderRadius="lg" border>
    I am a box.
  </Box>
  ```
</Example>

## Responsive sizing

Use Tailwind sizing values for width and height with responsive breakpoints. Resize your browser window to see this box change width: full width on mobile, half width on medium screens, and one-third on large screens.

<Example alignItems="stretch">
  <Box width={{ base: 'full', md: '1/2', lg: '1/3' }} padding="4" backgroundColor="muted" border borderRadius>
    Responsive width
  </Box>

  ```jsx
  <Box
    width={{ base: 'full', md: '1/2', lg: '1/3' }}
    padding="4"
    backgroundColor="muted"
    border
    borderRadius>
    Responsive width
  </Box>
  ```
</Example>

## State styles

Apply styles for hover, focus, and active states using object props. Each state accepts `color`, `backgroundColor`, `borderColor`, and `opacity`.

<Example>
  <Box
    padding="4"
    border
    borderRadius
    cursor="pointer"
    hover={{ color: 'red-600', backgroundColor: "red-100", borderColor: "red-500" }}
  >
    Hover over me
  </Box>

  ```jsx
  <Box
    padding="4"
    border
    borderRadius
    cursor="pointer"
    hover={{
      color: 'red-600',
      backgroundColor: "red-100",
      borderColor: "red-500"
    }}>
    Hover over me
  </Box>
  ```
</Example>

## Colors

Color props take a theme token name or a Tailwind palette color. The value is used as-is to build
the class: `backgroundColor="muted"` becomes `bg-muted` and `borderColor="red-500"` becomes
`border-red-500`. The exception is `color="muted"`, which becomes `text-muted-foreground`. Passing `true` uses the
default token (`text-foreground`, `bg-muted`, `border-border`).

| Prop | Theme tokens |
|------|--------------|
| `color` | `foreground`, `muted`, `primary`, `primary-foreground`, `secondary-foreground`, `accent-foreground`, `background`, `card-foreground`, `popover-foreground`, `destructive`, `success`, `warning`, `info` |
| `backgroundColor` | `background`, `card`, `popover`, `primary`, `secondary`, `muted`, `accent`, `foreground`, `sidebar`, `destructive`, `success`, `warning`, `info` |
| `borderColor` | `border`, `input`, `ring`, `primary`, `destructive`, `success`, `warning`, `info` |

Any Tailwind palette color also works, either as a name (`"blue"`, the 500 shade) or with a shade
(`"blue-100"`), as does `"transparent"`.

<Example>
  <Box padding="4" backgroundColor="primary" color="primary-foreground" borderRadius>
    Primary
  </Box>
  <Box padding="4" backgroundColor="muted" color="muted" borderRadius>
    Muted
  </Box>
  <Box padding="4" border borderColor="destructive" color="destructive" borderRadius>
    Destructive
  </Box>

  ```jsx
  <Box padding="4" backgroundColor="primary" color="primary-foreground" borderRadius>
    Primary
  </Box>
  <Box padding="4" backgroundColor="muted" color="muted" borderRadius>
    Muted
  </Box>
  <Box padding="4" border borderColor="destructive" color="destructive" borderRadius>
    Destructive
  </Box>
  ```
</Example>

## Dark theme

`theme="dark"` adds the `dark` class to the box, so everything inside it uses the dark-mode tokens
regardless of the page theme.

<Example>
  <Box theme="dark" padding="4" backgroundColor="background" color="foreground" border borderRadius>
    Always dark
  </Box>

  ```jsx
  <Box theme="dark" padding="4" backgroundColor="background" color="foreground" border borderRadius>
    Always dark
  </Box>
  ```
</Example>
