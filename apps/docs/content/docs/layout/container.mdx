A centered wrapper that constrains content to a maximum width. Essential for readable line lengths and consistent page layouts, especially for text-heavy content like articles or documentation.

<Example>
  <Dialog>
    <DialogTrigger render={<Button variant="outline" />}>Show container</DialogTrigger>
    <DialogContent className="sm:max-w-[calc(100%-2rem)]">
      <Container className="rounded-md bg-muted py-4">
        Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt
        ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation
        ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in

        est laborum.
      </Container>
    </DialogContent>
  </Dialog>

  ```jsx
  <Container>
    <Text>Content constrained to max-width</Text>
  </Container>
  ```
</Example>

The container is full width with `1rem` of horizontal padding, and has a `max-width` at each breakpoint.

| Size | Breakpoint | Max width |
| --- | --- | --- |
| base | 0px | none (full width) |
| sm | 640px | 500px |
| md | 768px | 740px |
| lg | 1024px | 1000px |
| xl | 1280px | 1240px |
| 2xl | 1536px | 1600px |

## Component props

<PropertiesTable>
  <PropertiesTable.Row name="centered" type="boolean">Centers the container horizontally (default: true)</PropertiesTable.Row>
  <PropertiesTable.Row name="fluid" type="boolean">Makes the container full width with no max-width constraint and no padding</PropertiesTable.Row>
</PropertiesTable>

Container also extends all [Box](/docs/layout/box) props.
