Zen's theme is the [shadcn/ui theme](https://ui.shadcn.com/docs/theming): a set of CSS variables on
`:root` with dark values on `.dark`. To customize Zen, override those variables. Because the names
are shadcn's, any shadcn theme works, including themes generated by
[ui.shadcn.com/create](https://ui.shadcn.com/create) and community theme builders.

## Overriding variables

Put your overrides in a stylesheet that loads **after** `@umami/react-zen/styles.css`. Define the
light values on `:root` and the dark values on `.dark`.

```css
@import "tailwindcss";
@import "@umami/react-zen/styles.css";

:root {
  --primary: oklch(0.546 0.245 262.881);
  --primary-foreground: oklch(0.985 0 0);
  --ring: oklch(0.707 0.165 254.624);
  --radius: 0.5rem;
}

.dark {
  --primary: oklch(0.707 0.165 254.624);
  --primary-foreground: oklch(0.205 0 0);
  --ring: oklch(0.546 0.245 262.881);
}
```

Every Zen and shadcn component reads these variables, so the change applies everywhere, and the
matching Tailwind utilities (`bg-primary`, `text-primary-foreground`, `ring-ring`) follow along.

## Using a shadcn theme

Copy the `:root` and `.dark` blocks of any shadcn theme into your stylesheet. You can leave out the
`@theme inline` block: Zen's stylesheet already maps every token to a Tailwind color.

Built-in [palettes](/docs/design/themes#color-palettes) are applied with `[data-palette="..."]`
selectors, and their dark values use `[data-palette="..."].dark`, which outranks a plain `.dark`
rule. If you supply a complete theme of your own, leave the palette at its default (`neutral`, which
has no palette rules), or scope your overrides with the same selectors:

```css
[data-palette="zinc"] {
  --primary: oklch(0.546 0.245 262.881);
}

[data-palette="zinc"].dark {
  --primary: oklch(0.707 0.165 254.624);
}
```

## Scoped themes

Variables cascade like any CSS custom property, so you can re-theme one part of the page by
overriding them on a selector.

```css
.marketing {
  --primary: oklch(0.645 0.246 16.439);
  --radius: 1rem;
}
```

## Radius

`--radius` is the base corner radius. Tailwind's radius scale is derived from it, so one variable
rounds every component.

| Utility | Value |
| --- | --- |
| `rounded-sm` | `calc(var(--radius) * 0.6)` |
| `rounded-md` | `calc(var(--radius) * 0.8)` |
| `rounded-lg` | `var(--radius)` |
| `rounded-xl` | `calc(var(--radius) * 1.4)` |
| `rounded-2xl` | `calc(var(--radius) * 1.8)` |
| `rounded-3xl` | `calc(var(--radius) * 2.2)` |
| `rounded-4xl` | `calc(var(--radius) * 2.6)` |

The default is `0.625rem`.

## CSS variable reference

### Theme tokens

| Variable | Usage |
| --- | --- |
| `--background`, `--foreground` | Page background and default text |
| `--card`, `--card-foreground` | Cards and raised panels |
| `--popover`, `--popover-foreground` | Menus, popovers and other floating surfaces |
| `--primary`, `--primary-foreground` | Brand color: default buttons, badges, selected states |
| `--secondary`, `--secondary-foreground` | Secondary buttons and badges |
| `--muted`, `--muted-foreground` | Subtle backgrounds; secondary text and placeholders |
| `--accent`, `--accent-foreground` | Hover and highlighted states of items |
| `--destructive` | Errors and destructive actions |
| `--border` | Default border color |
| `--input` | Form control borders |
| `--ring` | Focus rings |
| `--chart-1` … `--chart-5` | Chart series colors |
| `--sidebar`, `--sidebar-foreground`, `--sidebar-primary`, `--sidebar-primary-foreground`, `--sidebar-accent`, `--sidebar-accent-foreground`, `--sidebar-border`, `--sidebar-ring` | The Sidebar component |
| `--radius` | Base corner radius |

### Zen extensions

Zen adds a few variables that shadcn doesn't have. The status colors are used by `StatusLight`,
`Toast` and the color props, and are Tailwind colors like the rest (`text-success`, `bg-warning/10`).

| Variable | Usage |
| --- | --- |
| `--success` | Success states |
| `--warning` | Warning states |
| `--info` | Informational states |
| `--icon-size` | Default size of icons in components and of `Icon` without a `size` (default `14px`). Icons with an explicit `size-*` class keep it. |

If you paste in a shadcn theme, keep these or define your own values for them.

### Fonts

Zen ships no font and sets no font variable. Components inherit the font of your app. Set
`--font-sans` (and `--font-mono`) in Tailwind's theme to change it. See
[Fonts](/docs/design/fonts).

## Using OKLCH colors

shadcn themes use OKLCH values, written as `oklch(lightness chroma hue)`:

- **Lightness**: 0 (black) to 1 (white)
- **Chroma**: 0 (gray) to about 0.4 (vivid)
- **Hue**: 0–360 degrees

Any CSS color format works in an override, but OKLCH makes it easy to derive a lighter dark-mode
version of a color by raising its lightness.

## Tips

- Always override both `:root` and `.dark`, and check contrast in both.
- Override the `-foreground` pair along with its background so text stays readable.
- Use browser DevTools to experiment with variables live.
- Migrating from 0.x? The old `--zen-*` variables are removed. See the token mapping in the
  [migration guide](https://github.com/umami-software/react-zen/blob/master/MIGRATION-1.0.md).
