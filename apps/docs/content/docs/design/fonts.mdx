Zen ships no font and doesn't set a font family on its components. They inherit the font of your
app, which in a Tailwind app is Tailwind's `--font-sans` (and `--font-mono` for `Code`). Out of the
box that is the system font stack.

## Setting the font

Load the font however you like (a `<link>` to Google Fonts, `@fontsource`, `next/font`, a local
`@font-face`), then point Tailwind's font variables at it in your stylesheet:

```css
@import "tailwindcss";
@import "@umami/react-zen/styles.css";

@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
  --font-mono: "JetBrains Mono", ui-monospace, monospace;
}
```

Apps that use `styles.full.css` without Tailwind can set the font on `body` (and `code`, `pre`)
with plain CSS instead.

## Font sizes

Font sizes use Tailwind's native typography utilities. `size="sm"` maps to `text-sm`,
and `size="base"` maps to `text-base`. Text and standard controls default to `sm`.
The sizes below assume Tailwind's default theme and a 16px root font size; rem-based sizes
follow the host application's root font size.

## Usage in typography components

Font properties are used by typography components to control text appearance. [Text](/docs/typography/text) is the primary component for rendering text and accepts all font-related props. [Heading](/docs/typography/heading) uses a subset of larger sizes appropriate for headings.

- **size** - Controls the font size. Text defaults to `sm`, while Heading sizes map to appropriate heading levels.
- **weight** - Controls the font weight. Text defaults to `normal`, Heading defaults to `semibold`.

All font props accept responsive values for adapting typography across breakpoints.

## Customizing typography

Font sizes and their line heights come from Tailwind's `--text-*` theme variables, and weights from
`--font-weight-*`. Zen components use the same utilities as the rest of your application, so
changing them in `@theme` changes Zen too.
