Zen ships the [shadcn/ui](https://ui.shadcn.com/docs/theming) theme. Every color is a CSS variable,
and two switches change them all at once:

- **Dark mode** is the `.dark` class, exactly as in shadcn.
- **Palettes** are the shadcn base colors, selected with the `data-palette` attribute.

## Setup

Wrap your application with `ZenProvider`. It applies the stored or preferred theme and palette to
`<html>` and keeps the `useTheme` store in sync.

```jsx
import { ZenProvider } from '@umami/react-zen';

function App() {
  return (
    <ZenProvider>
      <YourApp />
    </ZenProvider>
  );
}
```

## Dark mode

Dark mode is the `.dark` class on an ancestor element, usually `<html>`. Any element inside a `.dark`
element uses the dark values of every token. Tailwind's `dark:` variant is wired to the same class.

```html
<html class="dark">
```

You can configure the initial theme with the `theme` or `colorScheme` props.

```jsx
// Force a specific theme
<ZenProvider theme="dark">

// Follow the system preference
<ZenProvider colorScheme="system">
```

Without either prop, Zen uses the stored preference, then the system preference. The preference is
saved to `localStorage` under the key `theme`, which is the same key `next-themes` uses, so the two
can be used together.

## Local themes

Pass a `target` to scope the theme to one element. `ThemeButton` then toggles the `dark` class on
that element only.

<Example>
  <ThemeButtonExample />

  ```jsx
  function LocalThemeExample() {
    const containerRef = useRef(null);

    return (
      <Box
        ref={containerRef}
        padding="6"
        border
        borderRadius="lg"
        backgroundColor="background"
        color="foreground"
        width="100%"
      >
        <Row alignItems="center" justifyContent="space-between" gap="6">
          <Text>This container has its own theme</Text>
          <ThemeButton variant="outline" target={containerRef} />
        </Row>
      </Box>
    );
  }
  ```
</Example>

To render a section in dark mode permanently, use `Box theme="dark"`, which adds the `dark` class.

## useTheme hook

Read and change the theme and palette programmatically with the `useTheme` hook.

```jsx
import { Button, useTheme } from '@umami/react-zen';

function MyComponent() {
  const { theme, setTheme } = useTheme();

  return (
    <Button
      variant="outline"
      onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}
    >
      Current theme: {theme}
    </Button>
  );
}
```

### Setting the palette

Set the palette with `ZenProvider`, with `useTheme`, or by writing the attribute yourself.

```jsx
// Via provider
<ZenProvider palette="zinc">
  <YourApp />
</ZenProvider>

// Programmatically
const { palette, setPalette } = useTheme();
setPalette('mauve');
```

```html
<html data-palette="stone" class="dark">
```

The palette is saved to `localStorage` under the key `zen.palette`. The exported `PALETTES` constant
lists every value.

## Tokens

Themes and palettes only change the values of the theme tokens. See [Colors](/docs/design/colors)
for the full list and [Customization](/docs/design/customization) to supply your own values.
