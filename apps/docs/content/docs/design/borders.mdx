title: Borders

import { Example, ExampleBox, Label } from '../../../mdx-components';

Borders are always solid and use the `border` theme token by default. You can control the `position`, `width`, `radius`, and `color` of borders.

## Border position

<Example gap="5">
  <Label>Default</Label>
  <ExampleBox border backgroundColor="muted" borderRadius="none" />
  <Label>Top</Label>
  <ExampleBox border="top" backgroundColor="muted" borderRadius="none" />
  <Label>Right</Label>
  <ExampleBox border="right" backgroundColor="muted" borderRadius="none" />
  <Label>Bottom</Label>
  <ExampleBox border="bottom" backgroundColor="muted" borderRadius="none" />
  <Label>Left</Label>
  <ExampleBox border="left" backgroundColor="muted" borderRadius="none" />

  ```jsx
  <ExampleBox border backgroundColor="muted" borderRadius="none" />
  <ExampleBox border="top" backgroundColor="muted" borderRadius="none" />
  <ExampleBox border="right" backgroundColor="muted" borderRadius="none" />
  <ExampleBox border="bottom" backgroundColor="muted" borderRadius="none" />
  <ExampleBox border="left" backgroundColor="muted" borderRadius="none" />
  ```
</Example>

## Border radius

Radius values are Tailwind's `rounded-*` utilities, which Zen derives from the `--radius` variable.
`lg` equals `--radius`; see [Customization](/docs/design/customization#radius).

<Example gap="5">
  <Label>sm</Label>
  <ExampleBox borderRadius="sm" />
  <Label>md</Label>
  <ExampleBox borderRadius="md" />
  <Label>lg</Label>
  <ExampleBox borderRadius="lg" />
  <Label>xl</Label>
  <ExampleBox borderRadius="xl" />
  <Label>2xl</Label>
  <ExampleBox borderRadius="2xl" />
  <Label>full</Label>
  <ExampleBox borderRadius="full" />

  ```jsx
  <ExampleBox borderRadius="sm" />
  <ExampleBox borderRadius="md" />
  <ExampleBox borderRadius="lg" />
  <ExampleBox borderRadius="xl" />
  <ExampleBox borderRadius="2xl" />
  <ExampleBox borderRadius="full" />
  ```
</Example>

## Border color

Use a theme token (`border`, `input`, `ring`, `primary`, `destructive`, `success`, `warning`, `info`)
or a Tailwind palette color.

<Example gap="5" direction="row">
  <ExampleBox />
  <ExampleBox borderColor="input" />
  <ExampleBox borderColor="primary" />
  <ExampleBox borderColor="destructive" />
  <ExampleBox borderColor="blue-500" />

  ```jsx
  <ExampleBox />
  <ExampleBox borderColor="input" />
  <ExampleBox borderColor="primary" />
  <ExampleBox borderColor="destructive" />
  <ExampleBox borderColor="blue-500" />
  ```
</Example>
