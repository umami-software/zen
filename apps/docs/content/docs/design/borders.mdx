Borders are always solid with a default border color. You can control the `position`, `radius`, and `color` of borders.

## Border position

<Example gap="5">
  <Label>Default</Label>
  <ExampleBox border backgroundColor="surface-raised" borderRadius="none" />
  <Label>Top</Label>
  <ExampleBox border="top" backgroundColor="surface-raised" borderRadius="none" />
  <Label>Right</Label>
  <ExampleBox border="right" backgroundColor="surface-raised" borderRadius="none" />
  <Label>Bottom</Label>
  <ExampleBox border="bottom" backgroundColor="surface-raised" borderRadius="none" />
  <Label>Left</Label>
  <ExampleBox border="left" backgroundColor="surface-raised" borderRadius="none" />

  ```jsx
  <ExampleBox border backgroundColor="surface-raised" borderRadius="none" />
  <ExampleBox border="top" backgroundColor="surface-raised" borderRadius="none" />
  <ExampleBox border="right" backgroundColor="surface-raised" borderRadius="none" />
  <ExampleBox border="bottom" backgroundColor="surface-raised" borderRadius="none" />
  <ExampleBox border="left" backgroundColor="surface-raised" borderRadius="none" />
  ```
</Example>
