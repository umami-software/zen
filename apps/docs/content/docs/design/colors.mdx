Zen uses the [shadcn/ui](https://ui.shadcn.com/docs/theming) color system. There are two kinds of
colors:

- **Theme tokens** such as `background`, `foreground`, `primary` and `muted`. They are CSS variables
  that change with [dark mode and the palette](/docs/design/themes), and you can
  [override them](/docs/design/customization). Use them for almost everything.
- **Tailwind palette colors** such as `blue-500`. They are fixed and don't change with the theme.

## Theme tokens

Most tokens come in pairs: a background color and the foreground color for text on top of it.

Each token is a CSS variable (`--primary`) and a Tailwind color (`bg-primary`, `text-primary`,
`border-primary`), so it also works with opacity modifiers: `bg-success/10` is a soft success
background.

## Color props

Layout and typography components take colors through props: `color`, `backgroundColor`,
`borderColor`, their `hover`/`focus`/`active` versions, `decorationColor`, and Icon's
`strokeColor`/`fillColor`. The value is the token name, and it becomes the Tailwind class of the same
name: `backgroundColor="muted"` renders `bg-muted`. The exception is `color="muted"`, which renders
`text-muted-foreground`, since a text color is always a foreground.

<Example direction="row" gap="4">
  <Text color="foreground">Foreground</Text>
  <Text color="muted">Muted</Text>
  <Text color="primary">Primary</Text>
  <Text color="destructive">Destructive</Text>
  <Text color="success">Success</Text>

  ```jsx
  <Text color="foreground">Foreground</Text>
  <Text color="muted">Muted</Text>
  <Text color="primary">Primary</Text>
  <Text color="destructive">Destructive</Text>
  <Text color="success">Success</Text>
  ```
</Example>

Each prop accepts the tokens that make sense for it:

  <PropertiesTable.Row name="backgroundColor" type="BackgroundColor">"background" | "page" | "card" | "popover" | "primary" | "secondary" | "muted" | "accent" | "foreground" | "sidebar" | "destructive" | "success" | "warning" | "info" | PaletteColor | true</PropertiesTable.Row>
  <PropertiesTable.Row name="borderColor" type="BorderColor">"border" | "input" | "ring" | "primary" | "destructive" | "success" | "warning" | "info" | PaletteColor | true</PropertiesTable.Row>

`true` picks the default token: `foreground` for text, `muted` for backgrounds and `border` for
borders. `PaletteColor` is a Tailwind color name (`red`), a color with a shade (`red-300`) or
`transparent`.

## Tailwind palette colors

Any Tailwind color works in a color prop, with or without a shade (50–950). Without a shade, 500 is
used.

<Example direction="row" wrap="wrap">
  <AccentColorsExample />
</Example>

<Example direction="row" gap="4">
  <Text color="blue-300">blue-300</Text>
  <Text color="blue-500">blue-500</Text>
  <Text color="blue-700">blue-700</Text>
  <Text color="blue-900">blue-900</Text>

  ```jsx
  <Text color="blue-300">blue-300</Text>
  <Text color="blue-500">blue-500</Text>
  <Text color="blue-700">blue-700</Text>
  <Text color="blue-900">blue-900</Text>
  ```
</Example>

Palette colors don't adapt to dark mode. Prefer a theme token wherever one fits.

## Icon colors

Icons take the same values.

<Example direction="row" gap="4">
  <Icon color="success" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="muted" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="blue-500" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="purple-600" size="lg"><Lucide.Wifi /></Icon>

  ```jsx
  <Icon color="success" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="muted" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="blue-500" size="lg"><Lucide.Wifi /></Icon>
  <Icon color="purple-600" size="lg"><Lucide.Wifi /></Icon>
  ```
</Example>
