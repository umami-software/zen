Zen provides a complete form system built on [react-hook-form](https://react-hook-form.com/). The `Form` and `FormField` components handle validation, error display, and field state management with minimal boilerplate.

## How it works

The form system consists of several components that work together:

- **Form** - Wraps your form and provides react-hook-form context
- **FormField** - Connects any input component to the form with automatic value binding and validation
- **FormButtons** - A plain `div` that right-aligns the form's action buttons (`flex justify-end gap-3`)
- **FormSubmitButton** - A shadcn `Button` with `type="submit"` that shows a spinner and disables itself while the form is submitting
- **FormResetButton** - A shadcn `Button` (`variant="outline"` by default) that resets the form to its default values
- **FormFieldArray** / **FormController** - For dynamic lists of fields and fully custom bindings

`FormField` renders a shadcn `Field` with a `FieldLabel`, the control, a `FieldDescription` and a
`FieldError`, and connects them with `id`, `aria-invalid` and `aria-describedby`.

## Basic usage

Wrap your inputs with `FormField` components inside a `Form`. Each `FormField` needs a `name` that corresponds to a key in your form data.

<Example>
  <Box width="300px">
    <FormExample />
  </Box>

  ```jsx
  import {
    Checkbox,
    Form,
    FormButtons,
    FormField,
    FormResetButton,
    FormSubmitButton,
    PasswordField,
    TextField,
  } from '@umami/react-zen';

  function LoginForm() {
    const handleSubmit = (data) => {
      console.log(data); // { username: '...', password: '...', remember_password: false }
    };

    return (
      <Form
        defaultValues={{ username: '', password: '', remember_password: false }}
        onSubmit={handleSubmit}
      >
        <FormField name="username" label="Username" rules={{ required: 'Username is required' }}>
          <TextField autoComplete="off" />
        </FormField>
        <FormField name="password" label="Password" rules={{ required: 'Password is required' }}>
          <PasswordField autoComplete="off" />
        </FormField>
        <FormField name="remember_password" label="Remember me" orientation="horizontal">
          <Checkbox />
        </FormField>
        <FormButtons>
          <FormResetButton>Reset</FormResetButton>
          <FormSubmitButton>Submit</FormSubmitButton>
        </FormButtons>
      </Form>
    );
  }
  ```
</Example>

## Validation

Add validation rules to `FormField` using the `rules` prop. This uses react-hook-form's validation API.

<Example>
  <Box width="300px">
    <FormValidationExample />
  </Box>

  ```jsx
  const validateAge = (value) => {
    const age = Number(value);
    if (Number.isNaN(age)) return 'Must enter a number';
    if (age <= 18) return 'You must be older than 18';
    if (age >= 100) return 'Age must be less than 100';
    return true;
  };

  <Form defaultValues={{ name: '', age: '' }} onSubmit={handleSubmit}>
    <FormField name="name" label="Name" rules={{ required: 'Name is required' }}>
      <TextField />
    </FormField>
    <FormField
      name="age"
      label="Age"
      rules={{ required: 'Age is required', validate: validateAge }}
    >
      <TextField />
    </FormField>
    <FormButtons>
      <FormResetButton>Reset</FormResetButton>
      <FormSubmitButton>Submit</FormSubmitButton>
    </FormButtons>
  </Form>
  ```
</Example>

### Common validation rules

| Rule | Description |
|------|-------------|
| `required` | Field must have a value |
| `min` | Minimum value for numbers |
| `max` | Maximum value for numbers |
| `minLength` | Minimum string length |
| `maxLength` | Maximum string length |
| `pattern` | Regex pattern to match |
| `validate` | Custom validation function |

## Loading states

`FormSubmitButton` automatically shows a loading spinner and disables itself while the form is submitting. This happens when your `onSubmit` handler returns a Promise.

<Example>
  <Box width="300px">
    <FormLoadingExample />
  </Box>

  ```jsx
  <Form
    defaultValues={{ name: '' }}
    onSubmit={async (data) => {
      // Simulate API call
      await new Promise((resolve) => setTimeout(resolve, 2000));
      console.log('Submitted:', data);
    }}
  >
    <FormField name="name" label="Name" rules={{ required: 'Name is required' }}>
      <TextField />
    </FormField>
    <FormButtons>
      <FormSubmitButton>Save</FormSubmitButton>
    </FormButtons>
  </Form>
  ```
</Example>

By default the submit button is only disabled while the form is submitting (`isSubmitting`). Add
`requireValid` to also disable it while the form is unchanged (`isDirty` is false) or invalid
(`isValid` is false). This is only useful with `mode="onChange"` or `mode="all"`, because in
react-hook-form's default `onSubmit` mode `isValid` stays false until the first submit.

```jsx
<Form mode="onChange" defaultValues={{ name: '' }} onSubmit={handleSubmit}>
  <FormField name="name" label="Name" rules={{ required: 'Name is required' }}>
    <TextField />
  </FormField>
  <FormButtons>
    <FormSubmitButton requireValid>Save</FormSubmitButton>
  </FormButtons>
</Form>
```

Pass `loading` or `disabled` to override the automatic states.

## Error handling

Pass an `error` prop to `Form` to display a destructive `Alert` above the form. This is useful for showing server-side validation errors or API failures.

<Example>
  <Box width="300px">
    <FormErrorExample />
  </Box>

  ```jsx
  function MyForm() {
    const [error, setError] = useState(null);

    const handleSubmit = async (data) => {
      try {
        await api.submit(data);
      } catch (err) {
        setError(err.message);
      }
    };

    return (
      <Form
        defaultValues={{ email: '' }}
        error={error}
        onSubmit={handleSubmit}
      >
        <FormField name="email" label="Email">
          <TextField />
        </FormField>
        <FormButtons>
          <FormSubmitButton>Submit</FormSubmitButton>
        </FormButtons>
      </Form>
    );
  }
  ```
</Example>

## Binding controls

`FormField` clones its child and binds the field's value to it. The props it sets depend on the
control:

| Control | Props set by FormField |
|---------|------------------------|
| `Checkbox`, `Switch` | `checked` + `onCheckedChange` |
| `Toggle` | `pressed` + `onPressedChange` |
| `Input`, `Textarea`, `InputGroupInput`, `InputGroupTextarea`, native elements | `value` + native `onChange` event |
| `TextField`, `PasswordField`, `SearchField` | `value` + `onValueChange(value)` |
| Everything else (`Select`, `RadioGroup`, `Slider`, `ToggleGroup`, `Combobox`, `NumberField`, `DatePicker`, `List`, `CheckboxGroup`, ...) | `value` + `onValueChange(value)` |

It also passes `name`, `onBlur`, `ref`, `disabled`, `id`, `aria-invalid` and `aria-describedby`.
Use `orientation="horizontal"` to put the label next to the control, which suits checkboxes and
switches.

<Example>
  <Box width="300px">
    <FormInputsExample />
  </Box>

  ```jsx
  <Form defaultValues={defaultValues} onSubmit={handleSubmit}>
    <FormField name="name" label="Name">
      <TextField autoComplete="off" />
    </FormField>
    <FormField name="bio" label="Bio">
      <TextField autoComplete="off" asTextArea />
    </FormField>
    <FormField name="password" label="Password">
      <PasswordField autoComplete="off" />
    </FormField>
    <FormField name="search" label="Search">
      <SearchField autoComplete="off" />
    </FormField>
    <FormField name="select" label="Select">
      <Select items={options}>
        <SelectTrigger className="w-full">
          <SelectValue placeholder="Select an option" />
        </SelectTrigger>
        <SelectContent>
          {options.map(option => (
            <SelectItem key={option.value} value={option.value}>
              {option.label}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
    </FormField>
    <FormField name="checkbox" label="Checkbox" orientation="horizontal">
      <Checkbox />
    </FormField>
    <FormField name="radio" label="Radio">
      <RadioGroup>
        {options.map(option => (
          <Row key={option.value} alignItems="center" gap="2">
            <RadioGroupItem id={`radio-${option.value}`} value={option.value} />
            <Label htmlFor={`radio-${option.value}`}>{option.label}</Label>
          </Row>
        ))}
      </RadioGroup>
    </FormField>
    <FormField name="toggle" label="Toggle">
      <Toggle variant="outline" aria-label="Bold">
        <Bold />
      </Toggle>
    </FormField>
    <FormField name="switch" label="Switch" orientation="horizontal">
      <Switch />
    </FormField>
    <FormField name="slider" label="Slider">
      <Slider />
    </FormField>
    <FormField name="list" label="List">
      <List selectionMode="multiple">
        <ListItem value="one">One</ListItem>
        <ListItem value="two">Two</ListItem>
        <ListItem value="three">Three</ListItem>
        <ListItem value="four">Four</ListItem>
        <ListItem value="five">Five</ListItem>
      </List>
    </FormField>
    <FormButtons>
      <FormResetButton>Reset</FormResetButton>
      <FormSubmitButton>Submit</FormSubmitButton>
    </FormButtons>
  </Form>
  ```
</Example>

Give `Slider` an array default value (for example `slider: [50]`) so it renders a single thumb.

### Custom bindings

For a control that needs different wiring, pass a render function. It receives
`{ field, fieldState, context, controlProps }`. Spread `controlProps` on the control to keep the
label, description and error connected.

```jsx
<FormField name="color" label="Color">
  {({ field, controlProps }) => (
    <MyColorPicker
      {...controlProps}
      color={field.value}
      onColorChange={field.onChange}
      onBlur={field.onBlur}
    />
  )}
</FormField>
```

## Dynamic fields with FormFieldArray

Use `FormFieldArray` when you need to manage a list of fields that can be added or removed dynamically.

<Example>
  <Box width="300px">
    <FormFieldArrayExample />
  </Box>

  ```jsx
  <Form
    defaultValues={{ items: [{ name: 'Item 1' }] }}
    onSubmit={handleSubmit}
  >
    <FormFieldArray name="items" label="Items">
      {({ fields, append, remove, control }) => (
        <Column gap>
          {fields.map((field, index) => (
            <Row key={field.id} gap>
              <FormController control={control} name={`items.${index}.name`}>
                {({ field }) => (
                  <TextField
                    name={field.name}
                    value={field.value}
                    onValueChange={field.onChange}
                    onBlur={field.onBlur}
                  />
                )}
              </FormController>
              <Button variant="outline" onClick={() => remove(index)}>
                Remove
              </Button>
            </Row>
          ))}
          <Button
            variant="secondary"
            onClick={() => append({ name: `Item ${fields.length + 1}` })}
          >
            Add
          </Button>
        </Column>
      )}
    </FormFieldArray>
    <FormButtons>
      <FormResetButton>Reset</FormResetButton>
      <FormSubmitButton>Submit</FormSubmitButton>
    </FormButtons>
  </Form>
  ```
</Example>

## Accessing form state

The `Form` component accepts a render function as children, giving you access to the full react-hook-form API.

```jsx
<Form defaultValues={{ name: '' }} onSubmit={handleSubmit}>
  {({ watch, formState }) => (
    <>
      <FormField name="name" label="Name">
        <TextField />
      </FormField>
      <Text>Current value: {watch('name')}</Text>
      <Text color="muted">Form is dirty: {formState.isDirty ? 'Yes' : 'No'}</Text>
      <FormButtons>
        <FormSubmitButton>Submit</FormSubmitButton>
      </FormButtons>
    </>
  )}
</Form>
```

## Schema validation

Use the `resolver` prop to integrate with schema validation libraries like Zod or Yup.

```jsx
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const schema = z.object({
  email: z.string().email('Invalid email'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
});

function MyForm() {
  return (
    <Form
      resolver={zodResolver(schema)}
      defaultValues={{ email: '', password: '' }}
      onSubmit={handleSubmit}
    >
      <FormField name="email" label="Email">
        <TextField />
      </FormField>
      <FormField name="password" label="Password">
        <PasswordField />
      </FormField>
      <FormButtons>
        <FormSubmitButton>Submit</FormSubmitButton>
      </FormButtons>
    </Form>
  );
}
```

## Controlled forms

Use the `values` prop instead of `defaultValues` when you need to control form values externally. The form will reset when the values change.

```jsx
function EditUserForm({ user }) {
  return (
    <Form
      values={{ name: user.name, email: user.email }}
      onSubmit={handleSubmit}
    >
      <FormField name="name" label="Name">
        <TextField />
      </FormField>
      <FormField name="email" label="Email">
        <TextField />
      </FormField>
      <FormButtons>
        <FormSubmitButton>Save</FormSubmitButton>
      </FormButtons>
    </Form>
  );
}
```

## Preventing enter key submission

Use `preventSubmit` to stop the form from submitting when the user presses Enter. Useful for forms where you want explicit button clicks only.

```jsx
<Form preventSubmit onSubmit={handleSubmit}>
  <FormField name="search" label="Search">
    <TextField />
  </FormField>
  <FormButtons>
    <FormSubmitButton>Search</FormSubmitButton>
  </FormButtons>
</Form>
```

### FormButtons

A `div` with `flex items-center justify-end gap-3`. Accepts all `div` props; use `className` to
change the layout.

### FormController

A thin wrapper around react-hook-form's `Controller`. Pass `control` and `name`, and a render
function child receiving `{ field, fieldState, formState }`.
